# 14. 路径编辑详细需求

## 14.1 路径编辑器概述

### 14.1.1 路径编辑器 (PathEditor)

**位置**: `packages/core/src/path_editor/path_editor.ts`

**核心职责**:

- 管理路径编辑模式
- 处理路径节点选择
- 处理路径节点编辑
- 处理控制点调整

### 14.1.2 路径编辑模式

**激活方式**:

- 双击路径图形
- 选中路径后按 `Enter` 键

**退出方式**:

- ESC 键
- 点击空白区域
- 选择其他图形

## 14.2 路径数据结构

### 14.2.1 路径数据格式

**SVG Path 格式**:

- 使用 SVG path 命令
- 支持 `M`, `L`, `C`, `Q`, `Z` 等命令

**内部表示**:

- 路径节点数组
- 每个节点包含坐标和控制点信息

### 14.2.2 路径节点类型

**节点类型**:

- **直线节点**: 只有坐标，无控制点
- **曲线节点**: 有坐标和控制点（贝塞尔曲线）

**控制点**:

- **入控制点**: 进入该节点的控制点
- **出控制点**: 离开该节点的控制点

## 14.3 路径编辑操作

### 14.3.1 节点选择

**选择方式**:

- 点击节点
- 框选多个节点

**选中状态**:

- 高亮显示选中的节点
- 显示控制点

### 14.3.2 节点移动

**操作方式**:

- 拖拽节点
- 方向键微调

**效果**:

- 节点位置更新
- 路径形状改变
- 实时预览

### 14.3.3 控制点调整

**操作方式**:

- 拖拽控制点
- Alt 键独立控制两个控制点

**效果**:

- 曲线形状改变
- 实时预览

### 14.3.4 节点添加

**操作方式**:

- 在路径上点击
- 在路径段上插入节点

**效果**:

- 添加新节点
- 路径更精细

### 14.3.5 节点删除

**操作方式**:

- 选中节点后按 Delete
- 选中节点后按 Backspace

**效果**:

- 删除节点
- 路径简化

**限制**:

- 至少保留 2 个节点（闭合路径至少 3 个）

### 14.3.6 节点类型转换

**转换类型**:

- 直线节点 ↔ 曲线节点

**操作方式**:

- 快捷键或菜单

**效果**:

- 节点类型改变
- 控制点显示/隐藏

## 14.4 路径编辑工具

### 14.4.1 路径选择工具

**工具类型**: `pathSelect`

**功能**:

- 选择路径节点
- 移动节点
- 调整控制点

**激活**: 进入路径编辑模式时自动激活

### 14.4.2 路径绘制工具

**工具类型**: `drawPath`

**功能**:

- 在路径上添加节点
- 继续绘制路径

**激活**: 路径编辑模式下可用

## 14.5 路径编辑 UI

### 14.5.1 节点显示

**节点样式**:

- 填充: 白色
- 描边: 蓝色
- 大小: 7px

**选中节点**:

- 高亮显示
- 显示控制点

### 14.5.2 控制点显示

**控制点样式**:

- 填充: 白色
- 描边: 灰色
- 大小: 5px

**控制线**:

- 连接节点和控制点
- 显示曲线方向

### 14.5.3 路径预览

**预览方式**:

- 实时显示路径形状
- 显示控制点和控制线

## 14.6 路径编辑快捷键

### 14.6.1 编辑快捷键

**Delete/Backspace**: 删除选中节点

**方向键**: 微调节点位置

**Alt + 拖拽**: 独立控制控制点

### 14.6.2 退出快捷键

**ESC**: 退出路径编辑模式

## 14.7 路径编辑命令记录

### 14.7.1 命令记录

**记录内容**:

- 路径数据变化
- 节点位置变化
- 控制点位置变化

**支持**: 撤销/重做

### 14.7.2 批量更新

**更新方式**:

- 使用 Transaction 批量更新
- 一次性提交所有更改

## 14.8 空路径处理

### 14.8.1 空路径检测

**检测条件**:

- 路径节点数为 0
- 或路径数据无效

### 14.8.2 自动删除

**删除时机**:

- 退出路径编辑模式时
- 如果路径为空，自动删除

**例外**:

- 撤销操作时不移除（通过 `source === 'undo'` 判断）

## 14.9 路径编辑性能

### 14.9.1 性能优化

**优化策略**:

- 按需渲染
- 延迟计算
- 批量更新

### 14.9.2 复杂路径处理

**处理策略**:

- 限制节点数量（可选）
- 优化渲染算法
- 使用缓存
