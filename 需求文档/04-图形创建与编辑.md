# 4. 图形创建与编辑详细需求

## 4.1 矩形 (Rect)

### 4.1.1 创建流程

1. 选择矩形工具 (`R` 键)
2. 在画布上按下鼠标左键，确定起始点
3. 拖拽鼠标，实时预览矩形
4. 释放鼠标，完成创建
5. 图形添加到场景图，记录命令

### 4.1.2 属性详情

- **基础属性**:
  - `width`: 宽度（像素）
  - `height`: 高度（像素）
  - `x`, `y`: 位置（通过 transform 矩阵计算）
- **圆角属性**:
  - `rx`: 水平圆角半径
  - `ry`: 垂直圆角半径
  - 支持独立设置或统一设置
- **样式属性**:
  - `fill`: 填充（IPaint[]）
  - `stroke`: 描边（IPaint[]）
  - `strokeWidth`: 描边宽度
  - `opacity`: 透明度

### 4.1.3 编辑功能

- **缩放**: 拖拽控制点调整大小
- **圆角**: 通过属性面板调整圆角半径
- **变换**: 支持移动、旋转、缩放
- **约束**: Shift 键锁定正方形比例

## 4.2 椭圆 (Ellipse)

### 4.2.1 创建流程

同矩形创建流程，使用椭圆工具 (`O` 键)

### 4.2.2 属性详情

- **基础属性**:
  - `width`: 椭圆宽度（长轴）
  - `height`: 椭圆高度（短轴）
- **样式属性**: 同矩形

### 4.2.3 编辑功能

- **缩放**: 可独立调整宽度和高度
- **约束**: Shift 键锁定圆形比例
- **变换**: 支持所有标准变换

## 4.3 直线 (Line)

### 4.3.1 创建流程

1. 选择直线工具 (`L` 键)
2. 点击起始点
3. 拖拽到终点
4. 释放鼠标完成

### 4.3.2 属性详情

- **起点**: (x1, y1) - 通过 transform 和起点偏移计算
- **终点**: (x2, y2) - 通过 transform 和终点偏移计算
- **样式**:
  - `stroke`: 描边颜色
  - `strokeWidth`: 线条宽度
  - `opacity`: 透明度

### 4.3.3 编辑功能

- **移动**: 拖拽直线本身
- **调整端点**: 拖拽端点控制点
- **约束**: Shift 键锁定水平/垂直/45 度角

## 4.4 路径 (Path)

### 4.4.1 创建方式

#### 路径工具创建

1. 选择路径工具 (`P` 键)
2. 点击创建节点
3. 连续点击创建多段线
4. ESC 或双击完成

#### 钢笔工具创建

1. 选择钢笔工具
2. 点击创建直线节点
3. 拖拽创建曲线节点（贝塞尔曲线）
4. ESC 或双击完成

#### 铅笔工具创建

1. 选择铅笔工具
2. 在画布上自由绘制
3. 自动转换为路径
4. 支持曲线拟合容差设置

### 4.4.2 路径数据结构

- **路径数据**: 使用 SVG path 格式
- **命令类型**:
  - `M`: 移动到
  - `L`: 直线到
  - `C`: 三次贝塞尔曲线
  - `Q`: 二次贝塞尔曲线
  - `Z`: 闭合路径

### 4.4.3 路径编辑

- **节点编辑**: 双击路径进入编辑模式
- **节点操作**:
  - 移动节点
  - 添加节点（在路径上点击）
  - 删除节点（选中节点后 Delete）
  - 转换节点类型（直线/曲线）
- **控制点操作**:
  - 调整贝塞尔曲线控制点
  - 独立控制两个控制点（Alt 键）
- **路径操作**:
  - 闭合路径
  - 开放路径

## 4.5 文本 (Text)

### 4.5.1 创建流程

1. 选择文本工具 (`T` 键)
2. 点击画布创建文本输入框
3. 输入文本内容
4. 点击空白区域完成

### 4.5.2 文本属性

- **内容**: 文本字符串
- **字体族**: `fontFamily` (如 'Arial', 'sans-serif')
- **字体大小**: `fontSize` (像素，默认 12px)
- **字体样式**: `fontStyle` (normal, italic, bold)
- **行高**: `lineHeight` (倍数或像素)
- **字间距**: `letterSpacing` (像素)
- **文本对齐**: `textAlign` (left, center, right)
- **文本颜色**: 通过 `fill` 属性设置

### 4.5.3 文本编辑

- **内联编辑**: 双击文本进入编辑模式
- **文本选择**: 支持文本范围选择
- **光标**: 显示编辑光标位置
- **多行文本**: 支持换行和段落
- **自动换行**: 根据宽度自动换行

### 4.5.4 文本测量

- **宽度测量**: 使用 Canvas `measureText()` API
- **高度计算**: 基于字体大小和行高
- **自动调整**: 文本尺寸随内容变化

## 4.6 正多边形 (Regular Polygon)

### 4.6.1 创建流程

1. 选择多边形工具（通过菜单）
2. 设置边数（3-12）
3. 在画布上拖拽创建
4. 释放鼠标完成

### 4.6.2 属性详情

- **边数**: `sides` (3-12，默认 3)
- **中心点**: 多边形中心
- **半径**: 外接圆半径
- **旋转**: 支持旋转角度

### 4.6.3 编辑功能

- **边数调整**: 通过属性面板修改边数
- **大小调整**: 拖拽控制点调整半径
- **旋转**: 支持旋转调整

## 4.7 星形 (Star)

### 4.7.1 创建流程

1. 选择星形工具 (`S` 键)
2. 在画布上拖拽创建
3. 释放鼠标完成

### 4.7.2 属性详情

- **角数**: `spikes` (3-12，默认 5)
- **内半径比例**: `innerScale` (0-1，默认 0.3819660246372223)
- **外半径**: 星形外接圆半径
- **内半径**: 外半径 × innerScale

### 4.7.3 编辑功能

- **角数调整**: 通过属性面板修改角数
- **内半径调整**: 调整内半径比例
- **大小调整**: 拖拽控制点调整外半径
- **旋转**: 支持旋转调整

## 4.8 画板 (Frame)

### 4.8.1 创建流程

1. 选择画板工具 (`F` 键)
2. 在画布上拖拽创建画板区域
3. 释放鼠标完成

### 4.8.2 属性详情

- **尺寸**: 宽度和高度
- **位置**: X、Y 坐标
- **填充**: 默认白色，可自定义
- **自动调整**: `resizeToFit` 属性，自动适应子图形

### 4.8.3 功能特性

- **容器功能**: 可作为其他图形的父容器
- **嵌套支持**: 支持多层嵌套
- **自动调整**: 启用后自动调整大小以适应子图形
- **裁剪**: 子图形超出画板边界时被裁剪

### 4.8.4 编组功能

- **创建编组**: 选中多个图形后创建组（Frame）
- **取消编组**: 将组拆分为独立图形
- **组编辑**: 组内的图形可以独立编辑

## 4.9 图片 (Image)

### 4.9.1 创建方式

#### 上传方式

1. 选择图片工具 (`I` 键)
2. 点击画布，触发文件选择对话框
3. 选择图片文件
4. 图片加载后显示在画布上

#### 粘贴方式

1. 从剪贴板复制图片
2. 在编辑器中粘贴 (`Cmd/Ctrl + V`)
3. 自动创建图片图形

### 4.9.2 图片管理

- **图片缓存**: 使用 `ImgManager` 管理图片
- **Base64 支持**: 支持 base64 编码的图片
- **URL 支持**: 支持图片 URL
- **图片加载**: 异步加载，显示加载状态

### 4.9.3 属性详情

- **宽度**: 图片显示宽度
- **高度**: 图片显示高度
- **原始尺寸**: 保存图片原始尺寸
- **图片源**: `fill` 属性存储图片 URL 或 base64

### 4.9.4 编辑功能

- **缩放**: 保持宽高比缩放
- **裁剪**: 支持图片裁剪（未来功能）
- **变换**: 支持所有标准变换

## 4.10 图形变换统一说明

### 4.10.1 变换矩阵

所有图形使用统一的变换矩阵系统：

- **矩阵格式**: `[a, b, c, d, tx, ty]`
- **变换类型**:
  - 平移 (Translation): tx, ty
  - 缩放 (Scale): a, d
  - 旋转 (Rotation): a, b, c, d
  - 倾斜 (Skew): b, c

### 4.10.2 坐标系统

- **本地坐标**: 图形自身的坐标系
- **世界坐标**: 场景坐标系
- **变换计算**: 通过矩阵乘法进行坐标转换

### 4.10.3 变换操作

- **组合变换**: 支持多个变换的组合
- **变换顺序**: 先缩放，再旋转，最后平移
- **变换中心**: 可自定义变换中心点

## 4.11 图形属性统一说明

### 4.11.1 通用属性

所有图形都支持以下通用属性：

- `id`: 唯一标识符（UUID）
- `type`: 图形类型
- `objectName`: 对象名称
- `width`, `height`: 尺寸
- `transform`: 变换矩阵
- `opacity`: 透明度 (0-1)
- `visible`: 可见性 (boolean)
- `lock`: 锁定状态 (boolean)

### 4.11.2 样式属性

- `fill`: 填充数组 (IPaint[])
- `stroke`: 描边数组 (IPaint[])
- `strokeWidth`: 描边宽度

### 4.11.3 填充和描边类型

- **纯色 (Solid)**:
  - `type`: 'solid'
  - `attrs`: { r, g, b, a } (RGBA)
- **图片 (Image)**:
  - `type`: 'image'
  - `attrs`: { src: string } (图片 URL 或 base64)

### 4.11.4 多填充/描边

- 支持多个填充层叠加
- 支持多个描边层叠加
- 按数组顺序渲染（从下到上）

## 4.12 图形交互反馈

### 4.12.1 悬停效果

- **高亮**: 鼠标悬停时高亮图形边框
- **颜色**: `#1592fe` (蓝色)
- **宽度**: 2px
- **配置**: 可通过 `highlightLayersOnHover` 设置开启/关闭

### 4.12.2 选中效果

- **选中框**: 显示图形边界框
- **控制点**: 显示变换控制点
- **尺寸指示器**: 显示图形尺寸信息

### 4.12.3 拖拽反馈

- **实时预览**: 拖拽时实时更新图形位置/大小
- **吸附提示**: 显示吸附到网格或对象的提示线
- **约束提示**: 显示约束状态（如锁定比例）
