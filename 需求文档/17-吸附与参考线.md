# 17. 吸附与参考线详细需求

## 17.1 吸附系统概述

### 17.1.1 吸附助手 (SnapHelper)

**位置**: `packages/core/src/snap.ts`

**核心职责**:

- 提供智能吸附功能
- 计算吸附点
- 处理网格吸附和对象吸附

### 17.1.2 吸附类型

**网格吸附**:

- 对齐到像素网格
- 可配置网格间距

**对象吸附**:

- 对齐到其他图形边缘
- 对齐到中心线
- 对齐到参考线

## 17.2 网格吸附

### 17.2.1 像素网格

**显示条件**:

- 缩放级别 >= 8 (800%)
- 显示透明网格线
- 网格间距: 1 像素

**网格样式**:

- 颜色: `#cccccc55` (半透明灰色)
- 线宽: 1px
- 虚线样式: 可选

### 17.2.2 网格吸附配置

**配置项**:

- `enablePixelGrid`: 是否显示像素网格
- `snapToGrid`: 是否启用网格吸附
- `gridSnapX`: X 轴网格间距
- `gridSnapY`: Y 轴网格间距

### 17.2.3 网格吸附算法

**吸附计算**:

- 使用 `getClosestTimesVal()` 函数
- 找到最近的网格线
- 计算吸附距离

**吸附距离阈值**:

- 默认 8px（可配置）
- 超过阈值不吸附

## 17.3 对象吸附

### 17.3.1 吸附目标

**图形边缘**:

- 左边缘、右边缘、上边缘、下边缘
- 图形中心线

**吸附线类型**:

- 水平参考线
- 垂直参考线
- 图形对齐线

### 17.3.2 吸附距离

**吸附阈值**:

- 默认 8px
- 可配置吸附灵敏度

**吸附优先级**:

- 最近的吸附点优先
- 多重吸附时选择最佳

### 17.3.3 吸附反馈

**视觉反馈**:

- 显示吸附线
- 显示吸附距离提示
- 高亮吸附目标

**颜色**:

- 吸附线: `#f14f30ee` (红色半透明)
- 宽度: 1px

## 17.4 参考线系统

### 17.4.1 参考线管理器 (RefLine)

**位置**: `packages/core/src/ref_line.ts`

**核心职责**:

- 管理参考线集合
- 计算参考线位置
- 渲染参考线

### 17.4.2 参考线类型

**水平参考线**:

- 存储 Y 坐标
- 跨越画布宽度

**垂直参考线**:

- 存储 X 坐标
- 跨越画布高度

### 17.4.3 参考线数据结构

```typescript
interface IRefLine {
  id: string;
  type: 'horizontal' | 'vertical';
  position: number; // X 或 Y 坐标
}
```

### 17.4.4 参考线操作

**创建参考线**:

- 拖拽标尺创建
- 从图形边缘创建
- 手动输入位置

**移动参考线**:

- 拖拽参考线移动
- 精确位置调整

**删除参考线**:

- 拖拽出画布边界
- 右键菜单删除
- 快捷键删除

## 17.5 吸附与参考线显示

### 17.5.1 参考线渲染

**渲染位置**:

- 水平参考线: 覆盖整个画布宽度
- 垂直参考线: 覆盖整个画布高度

**样式**:

- 颜色: `#f14f30ee` (红色半透明)
- 宽度: 1px
- 端点: 显示拖拽手柄

### 17.5.2 吸附线显示

**临时显示**:

- 拖拽时实时显示
- 达到吸附距离时出现
- 拖拽结束时消失

**样式**:

- 颜色: `#f14f30ee` (红色半透明)
- 宽度: 1px
- 虚线样式

### 17.5.3 距离指示器

**显示内容**:

- 吸附距离数值
- 单位: px
- 精度: 1 位小数

**位置**:

- 吸附线附近
- 不遮挡操作内容

## 17.6 吸附配置

### 17.6.1 吸附设置

**配置项**:

- `snapToObjects`: 是否启用对象吸附
- `snapToGrid`: 是否启用网格吸附
- `refLineTolerance`: 参考线吸附容差

### 17.6.2 吸附灵敏度

**距离阈值**:

- 对象吸附: 8px
- 网格吸附: 8px
- 参考线吸附: 4px

**可配置性**:

- 支持自定义阈值
- 支持关闭特定吸附类型

## 17.7 吸附算法

### 17.7.1 距离计算

**几何距离**:

- 计算点到线的距离
- 计算点到点的距离
- 计算线段交点

**最优吸附点**:

- 收集所有候选吸附点
- 计算距离权重
- 选择最近的有效吸附点

### 17.7.2 吸附优先级

**优先级顺序**:

1. 参考线吸附（最高优先级）
2. 图形边缘吸附
3. 图形中心吸附
4. 网格吸附（最低优先级）

### 17.7.3 多重吸附

**处理方式**:

- 支持同时吸附到多个目标
- X 轴和 Y 轴独立计算
- 显示所有激活的吸附线

## 17.8 参考线持久化

### 17.8.1 存储方式

**存储位置**:

- 文档数据中
- 与图形数据一起保存

**数据格式**:

```json
{
  "refLines": {
    "horizontal": [100, 200],
    "vertical": [150, 300]
  }
}
```

### 17.8.2 导入导出

**导入**:

- 加载文档时恢复参考线
- 验证参考线数据

**导出**:

- 保存参考线到文档
- 序列化为 JSON 格式

## 17.9 吸附与参考线交互

### 17.9.1 鼠标交互

**创建参考线**:

- 从标尺拖拽创建
- Alt + 拖拽图形边缘创建

**移动参考线**:

- 直接拖拽参考线
- 精确位置输入

**删除参考线**:

- 拖拽出画布边界
- 右键菜单删除

### 17.9.2 快捷键支持

**参考线快捷键**:

- `Alt + 拖拽`: 从图形创建参考线
- `Delete`: 删除选中参考线

**吸附切换**:

- `Cmd/Ctrl + Shift + '`: 切换网格吸附
