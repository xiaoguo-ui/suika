# 15. 文本编辑详细需求

## 15.1 文本编辑器概述

### 15.1.1 文本编辑器 (TextEditor)

**位置**: `packages/core/src/text/text_editor.ts`

**核心职责**:

- 管理文本编辑模式
- 处理文本输入和编辑
- 管理文本光标和选择
- 处理文本格式化

### 15.1.2 文本编辑模式

**激活方式**:

- 双击文本图形
- 选中文本图形后按 `Enter` 键
- 使用文本工具点击画布

**退出方式**:

- ESC 键
- 点击空白区域
- 选择其他图形

## 15.2 文本创建

### 15.2.1 文本工具创建

**操作流程**:

1. 选择文本工具 (`T` 键)
2. 点击画布
3. 创建文本输入框
4. 输入文本内容
5. 点击空白区域完成

### 15.2.2 文本图形属性

**默认属性**:

- 字体大小: 12px
- 字体族: sans-serif
- 文本颜色: 黑色
- 宽度: 0（自动调整）
- 高度: 字体大小

### 15.2.3 文本位置

**定位方式**:

- 使用点击位置作为起始点
- 自动调整高度以适应文本

## 15.3 文本编辑

### 15.3.1 内联编辑

**激活方式**:

- 双击文本图形
- 或使用文本工具点击现有文本

**编辑界面**:

- 显示文本输入框
- 显示光标
- 支持文本选择
- 支持多行文本

### 15.3.2 文本输入框

**实现方式**:

- 使用隐藏的 HTML input 元素
- 位置固定在文本位置
- 透明背景
- 同步字体样式

**位置**: `packages/core/src/text/text_editor.ts` (createInputDom)

### 15.3.3 文本同步

**同步机制**:

- 编辑器输入 → 文本图形更新
- 实时更新文本内容
- 自动调整文本框尺寸

## 15.4 文本选择和光标

### 15.4.1 文本范围管理器 (RangeManager)

**位置**: `packages/core/src/text/range_manager.ts`

**功能**:

- 管理文本选择范围
- 管理光标位置
- 处理文本选择操作

### 15.4.2 光标显示

**光标样式**:

- 颜色: 黑色
- 宽度: 1px
- 高度: 字体大小

**位置计算**:

- 使用 Canvas `measureText()` 计算
- 考虑字体大小和字间距

### 15.4.3 文本选择

**选择功能**:

- 鼠标拖拽选择文本
- 键盘快捷键选择
- 显示选择高亮

**选择样式**:

- 背景颜色: 半透明蓝色
- 覆盖选中文本范围

## 15.5 文本属性

### 15.5.1 基础属性

**内容**:

- 文本字符串
- 支持多行（换行符分隔）
- 支持特殊字符

**尺寸**:

- 宽度: 自动计算或手动设置
- 高度: 自动计算

### 15.5.2 字体属性

**字体族**:

- 支持系统字体
- 支持自定义字体
- 默认: sans-serif

**字体大小**:

- 像素值
- 范围: 1px - 1000px
- 默认: 12px

**字体样式**:

- normal, italic, bold
- 支持组合

### 15.5.3 布局属性

**文本对齐**:

- left, center, right
- 默认: left

**行高**:

- 倍数或像素值
- 默认: 1.2

**字间距**:

- 像素值
- 默认: 0

### 15.5.4 颜色属性

**填充颜色**:

- 支持纯色
- 支持渐变（未来）
- 支持图片填充（未来）

## 15.6 文本渲染

### 15.6.1 Canvas 文本渲染

**渲染方式**:

- 使用 `ctx.fillText()` 渲染
- 支持多行文本
- 支持文本样式

**换行处理**:

- 按换行符分割
- 逐行渲染
- 计算每行位置

### 15.6.2 文本测量

**宽度测量**:

- `ctx.measureText()` 计算单行宽度
- 累加多行宽度

**高度计算**:

- 字体大小 × 行数 × 行高

### 15.6.3 文本边界

**边界计算**:

- 考虑文本填充
- 考虑描边宽度
- 用于碰撞检测

## 15.7 文本编辑快捷键

### 15.7.1 文本编辑快捷键

**Enter**: 换行

**Backspace/Delete**: 删除字符

**方向键**: 移动光标

**Shift + 方向键**: 扩展选择

### 15.7.2 退出快捷键

**ESC**: 退出文本编辑

**Enter** (单行): 确认编辑（未来功能）

## 15.8 文本编辑状态管理

### 15.8.1 编辑器状态

**激活状态**: `isActive()`

**文本图形**: `getTextGraphics()`

### 15.8.2 编辑器生命周期

**激活**:

- 创建输入框
- 设置文本内容
- 显示光标
- 绑定事件

**非激活**:

- 移除输入框
- 清除选择
- 重置状态

### 15.8.3 状态同步

**输入同步**:

- input 事件 → 更新文本内容
- 实时同步到图形

**选择同步**:

- 文本选择 → 更新范围
- 范围变化 → 更新显示

## 15.9 文本编辑事件处理

### 15.9.1 输入事件

**处理方式**:

- 监听 input 元素事件
- 同步到文本图形
- 更新文本尺寸

### 15.9.2 键盘事件

**处理方式**:

- 拦截特定按键
- 处理快捷键
- 更新光标位置

### 15.9.3 鼠标事件

**处理方式**:

- 点击设置光标
- 拖拽选择文本
- 双击选择单词

## 15.10 多行文本支持

### 15.10.1 换行处理

**换行符**:

- `\n` 表示换行
- 支持多行输入

**渲染**:

- 按行分割渲染
- 每行独立定位

### 15.10.2 自动换行

**当前状态**: 不支持（未来功能）

**未来实现**:
