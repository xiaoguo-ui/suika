# 5. 工具系统详细需求

## 5.1 工具系统概述

### 5.1.1 工具管理器 (ToolManager)

**位置**: `packages/core/src/tools/tool_manager.ts`

**核心职责**:

- 管理所有工具的注册和切换
- 处理工具快捷键绑定
- 管理工具状态（激活/非激活）
- 处理工具拖拽状态
- 控制工具启用/禁用

### 5.1.2 工具接口 (ITool)

所有工具必须实现 `ITool` 接口：

```typescript
interface ITool {
  type: string; // 工具类型
  hotkey: string | IKey; // 快捷键
  cursor: ICursor; // 光标类型
  onActive: () => void; // 激活时调用
  onInactive: () => void; // 非激活时调用
  onMoveExcludeDrag: (event, isOutsideCanvas) => void; // 移动事件
  onStart: (event) => void; // 开始操作
  onDrag: (event) => void; // 拖拽中
  onEnd: (event, isOutsideCanvas) => void; // 结束操作
  onComboClick?: (event) => void; // 双击
  getDragBlockStep?: () => number; // 拖拽步长
  enableActive?: () => Promise<boolean>; // 启用检查
}
```

## 5.2 工具列表

### 5.2.1 选择工具 (Select Tool)

**工具类型**: `select`
**快捷键**: `V`
**光标**: `default`

**功能**:

- 选择图形对象
- 移动选中图形
- 缩放选中图形
- 旋转选中图形
- 框选多个图形

**操作模式**:

1. **点选**: 点击图形选中
2. **框选**: 拖拽选择区域
3. **多选**: Shift + 点击添加选中项
4. **移动**: 拖拽选中框移动图形
5. **缩放**: 拖拽控制点缩放图形
6. **旋转**: 拖拽旋转控制点

**特殊功能**:

- 双击进入编辑模式（文本/路径）
- 双击组进入组编辑模式

### 5.2.2 矩形工具 (Rectangle Tool)

**工具类型**: `drawRect`
**快捷键**: `R`
**光标**: `crosshair`

**功能**: 创建矩形图形

**操作流程**:

1. 按下鼠标，记录起始点
2. 拖拽鼠标，实时预览矩形
3. 释放鼠标，完成创建
4. 根据设置决定是否切换回选择工具

**约束**:

- Shift: 创建正方形
- Alt: 从中心创建
- 网格吸附: 吸附到网格点

### 5.2.3 椭圆工具 (Ellipse Tool)

**工具类型**: `drawEllipse`
**快捷键**: `O`
**光标**: `crosshair`

**功能**: 创建椭圆图形

**操作流程**: 同矩形工具

**约束**:

- Shift: 创建圆形
- Alt: 从中心创建

### 5.2.4 直线工具 (Line Tool)

**工具类型**: `drawLine`
**快捷键**: `L`
**光标**: `crosshair`

**功能**: 创建直线图形

**操作流程**:

1. 按下鼠标，记录起点
2. 拖拽到终点
3. 释放鼠标，完成创建

**约束**:

- Shift: 锁定水平/垂直/45 度角
- 网格吸附: 吸附到网格点

### 5.2.5 路径工具 (Path Tool)

**工具类型**: `drawPath`
**快捷键**: `P`
**光标**: `crosshair`

**功能**: 创建多段线路径

**操作流程**:

1. 点击创建节点
2. 连续点击创建多段线
3. ESC 或双击完成路径

**特性**:

- 支持连续线段
- 支持闭合路径
- 自动转换为路径图形

### 5.2.6 钢笔工具 (Pen Tool)

**工具类型**: `drawPen`
**快捷键**: 无（通过菜单访问）
**光标**: `crosshair`

**功能**: 创建贝塞尔曲线路径

**操作流程**:

1. 点击创建直线节点
2. 拖拽创建曲线节点（贝塞尔曲线）
3. ESC 或双击完成

**特性**:

- 支持直线段
- 支持贝塞尔曲线段
- 支持控制点调整

### 5.2.7 铅笔工具 (Pencil Tool)

**工具类型**: `pencil`
**快捷键**: 无（通过菜单访问）
**光标**: `crosshair`

**功能**: 自由绘制路径

**操作流程**:

1. 按下鼠标开始绘制
2. 拖拽自由绘制
3. 释放鼠标完成
4. 自动转换为路径（曲线拟合）

**特性**:

- 曲线拟合容差可配置
- 自动平滑处理
- 转换为优化的路径

### 5.2.8 文本工具 (Text Tool)

**工具类型**: `drawText`
**快捷键**: `T`
**光标**: `text`

**功能**: 创建文本图形

**操作流程**:

1. 点击画布，创建文本输入框
2. 输入文本内容
3. 点击空白区域完成

**特性**:

- 支持多行文本
- 支持文本格式化
- 自动调整文本框大小

### 5.2.9 图片工具 (Image Tool)

**工具类型**: `drawImg`
**快捷键**: `I`
**光标**: `crosshair`

**功能**: 创建图片图形

**操作流程**:

1. 点击画布，触发文件选择
2. 选择图片文件
3. 图片加载后显示在画布上

**特性**:

- 支持多种图片格式
- 支持从剪贴板粘贴
- 自动调整尺寸

### 5.2.10 画板工具 (Frame Tool)

**工具类型**: `drawFrame`
**快捷键**: `F`
**光标**: `crosshair`

**功能**: 创建画板容器

**操作流程**: 同矩形工具

**特性**:

- 作为容器使用
- 支持自动调整大小
- 支持子图形嵌套

### 5.2.11 抓手工具 (Hand Tool)

**工具类型**: `dragCanvas`
**快捷键**: `H` 或空格键
**光标**: `grab` / `grabbing`

**功能**: 拖拽画布

**操作流程**:

1. 按下鼠标
2. 拖拽移动画布视口
3. 释放鼠标完成

**特性**:

- 临时切换: 空格键临时切换为抓手工具
- 视口移动: 改变视口位置，不改变图形位置

### 5.2.12 路径选择工具 (Path Select Tool)

**工具类型**: `pathSelect`
**快捷键**: 无（通过双击路径激活）

**功能**: 编辑路径节点

**操作流程**:

1. 双击路径图形，进入编辑模式
2. 选择节点
3. 拖拽节点或控制点
4. ESC 退出编辑模式

**特性**:

- 节点选择
- 节点移动
- 控制点调整
- 添加/删除节点
- 转换节点类型

## 5.3 工具状态管理

### 5.3.1 工具激活

**激活流程**:

1. 用户选择工具（点击工具栏或快捷键）
2. 调用 `ToolManager.setActiveTool(type)`
3. 当前工具 `onInactive()` 被调用
4. 新工具 `onActive()` 被调用
5. 更新工具栏 UI 状态

### 5.3.2 工具切换

**切换规则**:

- 快捷键切换: 直接切换到对应工具
- 工具栏切换: 点击工具栏按钮切换
- 自动切换: 某些工具使用后自动切换回选择工具（可配置）

**配置项**:

- `keepToolSelectedAfterUse`: 使用工具后是否保持选中状态

### 5.3.3 工具禁用

**禁用场景**:

- 某些特殊模式下禁用特定工具
- 可通过 `ToolManager.setEnableTools()` 控制可用工具列表

### 5.3.4 工具拖拽状态

**拖拽检测**:

- `ToolManager.isDragging()`: 检查是否正在拖拽
- 用于防止快捷键在拖拽时触发

## 5.4 工具快捷键系统

### 5.4.1 快捷键绑定

**绑定方式**:

- 工具注册时自动绑定快捷键
- 通过 `KeyBindingManager` 统一管理

**快捷键格式**:

- 简单键: `'R'` → `KeyR`
- 组合键: `{ metaKey: true, keyCode: 'KeyZ' }` → Cmd+Z

### 5.4.2 工具快捷键列表

| 选择       | V      | V     | V       |

| 椭圆       | O      | O     | O       |
| 直线       | L      | L     | L       |

## 5.5 工具光标系统

### 5.5.1 光标类型 (ICursor)

**支持的光标类型**:

- `default`: 默认箭头
- `crosshair`: 十字准星（绘图工具）
- `text`: 文本光标（文本工具）
- `grab`: 抓手（可抓取）
- `grabbing`: 抓手（抓取中）
- `move`: 移动
- `resize-*`: 各种调整大小光标
- `rotate`: 旋转

**位置**: `packages/core/src/cursor_manager/`

**光标资源**:

- 使用 PNG 图片作为自定义光标
- 支持不同缩放级别的高清光标

### 5.5.2 光标切换

**切换时机**:

- 工具激活时切换光标
- 鼠标悬停在图形上时切换光标
- 拖拽操作时切换光标

## 5.6 工具事件处理

### 5.6.1 鼠标事件

**事件流程**:

```
mousedown → onStart()
mousemove → onMoveExcludeDrag() / onDrag()
mouseup → onEnd()
dblclick → onComboClick()
```

### 5.6.2 事件坐标转换

**坐标转换**:

- 屏幕坐标 → 视口坐标 → 场景坐标
- 使用 `viewportCoordsToSceneUtil()` 转换

### 5.6.3 事件处理顺序

1. **HostEventManager**: 捕获浏览器事件
2. **ToolManager**: 分发到当前工具
3. **Tool**: 处理具体逻辑
4. **Graphics**: 更新图形状态
5. **SceneGraph**: 更新场景
6. **Render**: 重新渲染

## 5.7 工具扩展机制

### 5.7.1 注册新工具

**步骤**:

1. 创建工具类，实现 `ITool` 接口
2. 在 `ToolManager` 构造函数中注册：

   ```typescript
   this.registerToolCtor(MyTool);
   ```

3. 添加到可用工具列表：

   ```typescript
   this.setEnableHotKeyTools([..., MyTool.type]);
   ```

### 5.7.2 工具基类

**DrawGraphicsTool**: 绘图工具的基类

- 提供通用的绘图逻辑
- 处理拖拽、预览、创建等通用功能
- 子类只需实现 `createGraphics()` 方法

### 5.7.3 工具配置

**工具配置项**:

- `keepToolSelectedAfterUse`: 使用后是否保持选中
- `getDragBlockStep()`: 拖拽步长（用于某些特殊工具）
