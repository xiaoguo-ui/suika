# 19. 导入导出详细需求

## 19.1 数据格式概述

### 19.1.1 编辑器数据格式 (IEditorPaperData)

**位置**: `packages/core/src/type.ts`

**数据结构**:

```typescript
interface IEditorPaperData {
  appVersion: string;      // 应用版本
  paperId: string;         // 图纸 ID
  data: GraphicsAttrs[];   // 图形数据数组
}
```

### 19.1.2 图形属性 (GraphicsAttrs)

**位置**: `packages/core/src/graphics/graphics/graphics_attrs.ts`

**包含属性**:

- 基本属性: type, id, objectName, width, height
- 变换属性: transform
- 样式属性: fill, stroke, strokeWidth, opacity
- 状态属性: visible, lock
- 关系属性: parentIndex

## 19.2 导出功能

### 19.2.1 数据序列化

**序列化流程**:

1. 收集所有图形数据
2. 转换为标准格式
3. 生成 JSON 字符串
4. 提供下载或复制

### 19.2.2 导出方式

**JSON 导出**:

- 导出完整图纸数据
- 包含所有图形和属性
- 支持重新导入

**SVG 导出**:

- 导出为 SVG 格式
- 转换为矢量图形
- 支持浏览器原生下载

### 19.2.3 导出配置

**导出选项**:

- 包含隐藏图形: 默认 false
- 包含锁定图形: 默认 true
- 导出格式: JSON/SVG

## 19.3 导入功能

### 19.3.1 数据反序列化

**反序列化流程**:

1. 解析 JSON 数据
2. 验证数据格式
3. 创建图形对象
4. 恢复图形关系
5. 添加到场景图

### 19.3.2 导入验证

**验证内容**:

- JSON 格式正确性
- 应用版本兼容性
- 数据完整性
- 图形类型有效性

### 19.3.3 冲突处理

**ID 冲突**:

- 重新生成图形 ID
- 避免与现有图形冲突

**名称冲突**:

- 自动重命名
- 添加序号后缀

## 19.4 文件操作

### 19.4.1 本地文件导入

**操作方式**:

1. 点击导入按钮
2. 选择 JSON 文件
3. 读取文件内容
4. 解析并导入数据

**文件类型**: `.json`

**大小限制**: 默认无限制（可配置）

### 19.4.2 本地文件导出

**操作方式**:

1. 点击导出按钮
2. 选择保存位置
3. 生成并下载文件

**默认文件名**: `suika-paper-{timestamp}.json`

## 19.5 自动保存

### 19.5.1 本地存储

**存储位置**: localStorage

**存储键**: `suika-paper`

**保存时机**:

- 每次命令执行后
- 使用防抖延迟保存（10ms）

### 19.5.2 自动恢复

**恢复时机**:

- 编辑器初始化时
- 检查本地存储数据
- 验证版本兼容性

**恢复流程**:

1. 读取本地数据
2. 验证版本
3. 询问用户是否恢复
4. 加载数据或清空

## 19.7 SVG 导出

### 19.7.1 SVG 生成

**位置**: `packages/core/src/to_svg.ts`

**生成内容**:

- SVG 根元素
- 图形路径元素
- 样式属性转换
- 变换矩阵应用

### 19.7.2 样式转换

**填充转换**:

- 纯色: `fill="rgba(r,g,b,a)"`
- 图片: `fill="url(#pattern)"`

**描边转换**:

- 颜色: `stroke="rgba(r,g,b,a)"`
- 宽度: `stroke-width="value"`

### 19.7.3 路径生成

**路径数据**:

- 转换为 SVG path 格式
- 支持所有图形类型
- 保持路径精确性
