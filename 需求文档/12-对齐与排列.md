# 12. 对齐与排列详细需求

## 12.1 对齐系统概述

### 12.1.1 对齐功能

**位置**: `packages/core/src/service/align_and_record.ts`

**核心功能**: 将多个选中图形对齐到指定位置

**对齐类型**:

- 左对齐 (Left)
- 水平居中 (Horizontal Center)
- 右对齐 (Right)
- 上对齐 (Top)
- 垂直居中 (Vertical Center)
- 下对齐 (Bottom)

### 12.1.2 对齐条件

**最小要求**: 至少选中 2 个图形

**限制**: 少于 2 个图形时静默失败

## 12.2 对齐操作

### 12.2.1 左对齐 (Align Left)

**对齐方式**: 所有图形的左边缘对齐

**参考点**: 最左侧图形的左边缘

**快捷键**: `Alt + A`

**实现**:

1. 计算所有图形的边界框
2. 找到最左侧的位置
3. 将所有图形移动到该位置

### 12.2.2 水平居中 (Align Horizontal Center)

**对齐方式**: 所有图形的水平中心对齐

**参考点**: 所有图形的合并边界框的水平中心

**快捷键**: `Alt + H`

**实现**:

1. 计算所有图形的边界框
2. 计算合并边界框的水平中心
3. 将所有图形的水平中心移动到该位置

### 12.2.3 右对齐 (Align Right)

**对齐方式**: 所有图形的右边缘对齐

**实现**:

### 12.2.4 上对齐 (Align Top)

**对齐方式**: 所有图形的上边缘对齐

**参考点**: 最上方图形的上边缘

**快捷键**: `Alt + W`

**实现**:

1. 计算所有图形的边界框

### 12.2.5 垂直居中 (Align Vertical Center)

**对齐方式**: 所有图形的垂直中心对齐

## 12.3 对齐算法

### 12.3.1 边界框计算

**计算方式**:

- 获取每个图形的世界坐标边界框
- 考虑图形的变换矩阵
- 使用 `getBbox()` 方法

### 12.3.2 合并边界框

**计算方式**:

- 合并所有图形的边界框
- 使用 `mergeBoxes()` 函数
- 得到包含所有图形的最小矩形

### 12.3.3 对齐参考点

**参考点类型**:

1. **边缘对齐**: 使用最边缘的位置
2. **中心对齐**: 使用合并边界框的中心

**计算方式**:

- 边缘对齐: 找到最边缘的坐标值
- 中心对齐: 计算合并边界框的中心坐标

### 12.3.4 位置更新

**更新方式**:

1. 计算每个图形需要移动的距离
2. 更新图形的世界变换矩阵
3. 只更新平移部分 (tx, ty)
4. 保持其他变换不变

## 12.4 对齐优化

### 12.4.1 已对齐检测

**功能**: 检测图形是否已经对齐

**实现**:

- 计算所有图形的对齐值
- 比较是否相等（考虑浮点误差）
- 如果已对齐，不执行对齐操作

**优势**:

- 避免不必要的命令记录
- 提高用户体验

### 12.4.2 对齐精度

**精度处理**:

- 使用浮点数比较
- 考虑浮点误差容差
- 使用 `getClosestTimesVal()` 处理网格对齐

## 12.5 对齐命令记录

### 12.5.1 命令记录

**记录方式**: 使用 Transaction

**记录内容**:

- 每个图形移动前的变换矩阵
- 每个图形移动后的变换矩阵

**支持**: 撤销/重做

### 12.5.2 批量更新

**更新方式**:

- 使用 Transaction 批量更新
- 一次性提交所有更改
- 作为单个命令记录

## 12.6 排列系统概述

### 12.6.1 排列功能

**位置**: `packages/core/src/service/arrange_and_record.ts`

**核心功能**: 调整图形在图层中的顺序（Z-order）

**排列类型**:

- 移到顶部 (Front)
- 移到底部 (Back)
- 上移一层 (Forward)
- 下移一层 (Backward)

### 12.6.2 排序算法

**算法**: Fractional Indexing

**库**: `fractional-indexing`

**优势**:

- 支持任意位置插入
- 不需要重新排序所有元素
- 性能优秀

## 12.7 排列操作

### 12.7.1 移到顶部 (Front)

**操作**: 将选中图形移到当前容器的最上层

**快捷键**: `]`

**实现**:

1. 获取当前容器的所有子图形
2. 找到选中图形的最大排序索引
3. 生成新的排序索引（在最大索引之后）
4. 更新选中图形的排序索引

### 12.7.2 移到底部 (Back)

**操作**: 将选中图形移到当前容器的最下层

**快捷键**: `[`

**实现**:

1. 获取当前容器的所有子图形
2. 找到选中图形的最小排序索引
3. 生成新的排序索引（在最小索引之前）
4. 更新选中图形的排序索引

### 12.7.3 上移一层 (Forward)

**操作**: 将选中图形在当前容器内上移一层

**快捷键**: `Cmd/Ctrl + ]`

**实现**:

1. 获取当前容器的所有子图形
2. 找到选中图形后面的第一个图形
3. 如果存在，交换排序索引
4. 如果不存在，不执行操作

### 12.7.4 下移一层 (Backward)

**操作**: 将选中图形在当前容器内下移一层

**快捷键**: `Cmd/Ctrl + [`

**实现**:

1. 获取当前容器的所有子图形
2. 找到选中图形前面的第一个图形
3. 如果存在，交换排序索引
4. 如果不存在，不执行操作

## 12.8 排列算法

### 12.8.1 排序索引管理

**存储方式**: `parentIndex.position`

**格式**: Fractional Index 字符串

**生成方式**: `generateKeyBetween()`, `generateNKeysBetween()`

### 12.8.2 多图形排列

**处理方式**:

- 按父容器分组
- 每个父容器内独立排列
- 保持图形相对顺序

### 12.8.3 排列限制

**限制规则**:

- 只能在同一个父容器内排列
- 不能跨容器排列
- 锁定的图形不参与排列（可选）

## 12.9 排列优化

### 12.9.1 无变化检测

**功能**: 检测排列操作是否实际改变顺序

**实现**:

- 比较排列前后的顺序
- 如果顺序未改变，不执行操作
- 不记录命令

### 12.9.2 批量排列

**处理方式**:

- 多个图形同时排列时保持相对顺序
- 作为一个整体移动到目标位置
- 使用 `generateNKeysBetween()` 生成连续索引

## 12.10 对齐与排列 UI

### 12.10.1 对齐按钮

**位置**: 属性面板对齐卡片

**显示条件**: 选中 2 个或更多图形时启用

**按钮类型**: 6 个对齐按钮

### 12.10.2 排列按钮

**位置**: 右键菜单

**快捷键**: 见上述快捷键列表

### 12.10.3 按钮状态

**启用/禁用**:

- 对齐按钮: 选中数量 >= 2 时启用
- 排列按钮: 选中数量 >= 1 时启用

**视觉反馈**:

- 启用: 正常显示
- 禁用: 灰显

## 12.11 对齐与排列命令

### 12.11.1 命令记录

**对齐命令**:

- 记录移动前的变换矩阵
- 记录移动后的变换矩阵
- 支持撤销/重做

**排列命令**:

- 记录排列前的排序索引
- 记录排列后的排序索引
- 支持撤销/重做

### 12.11.2 命令描述

**对齐命令**: `Align ${AlignType}`

**排列命令**: `Arrange ${ArrangeType}`

## 12.12 对齐与排列性能

### 12.12.1 性能优化

**优化策略**:

- 批量更新
- 延迟渲染
- 避免不必要的计算

### 12.12.2 大量图形处理

**处理策略**:

- 只处理可见图形
- 使用高效算法
- 限制处理数量（可选）
