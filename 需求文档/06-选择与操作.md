# 6. 选择与操作详细需求

## 6.1 选择系统概述

### 6.1.1 选择管理器 (SelectedElements)

**位置**: `packages/core/src/selected_elements.ts`

**核心职责**:

- 管理当前选中的图形对象列表
- 处理选择操作（单选、多选、框选）
- 管理悬停状态
- 提供选择变化事件

### 6.1.2 选择状态

**状态类型**:

- **选中项**: 当前选中的图形对象数组
- **悬停项**: 鼠标悬停的图形对象
- **选中数量**: 选中项的数量

## 6.2 选择操作

### 6.2.1 单选

**操作方式**:

- 点击图形对象
- 点击图层面板中的图形项

**行为**:

1. 清除之前的选择
2. 选中点击的图形
3. 显示选中框和控制点
4. 触发 `itemsChange` 事件

**特殊情况**:

- 点击已选中的图形：保持选中状态
- 点击空白区域：取消选择
- 点击锁定的图形：不选中

### 6.2.2 多选

**操作方式**:

1. **Shift + 点击**:
   - 点击未选中的图形：添加到选中列表
   - 点击已选中的图形：从选中列表移除
2. **Ctrl/Cmd + 点击**: 同 Shift + 点击

**行为**:

- 支持添加多个图形到选中列表
- 支持从选中列表移除图形
- 显示合并的选中框

### 6.2.3 框选

**操作方式**:

- 在空白区域按下鼠标
- 拖拽形成选择矩形
- 释放鼠标完成选择

**选择模式**:

- **intersect** (默认): 与选区相交的图形即被选中
- **contain**: 完全包含在选区内的图形才被选中

**配置**:

- `selectionMode`: 'intersect' | 'contain'
- 通过 `setting.selectionMode` 配置

**选择算法**:

1. 计算选择矩形的边界框
2. 遍历场景图中的图形
3. 检测图形边界框与选择矩形的关系
4. 根据选择模式判断是否选中

### 6.2.4 全选

**操作方式**:

- 快捷键: `Cmd/Ctrl + A`
- 菜单: 编辑 → 全选

**行为**:

1. 选中所有可见且未锁定的图形
2. 排除锁定的图形
3. 排除隐藏的图形
4. 触发 `itemsChange` 事件

### 6.2.5 反选

**当前状态**: 未实现（可扩展）

### 6.2.6 取消选择

**操作方式**:

- 点击空白区域
- ESC 键（某些情况下）
- 选择其他图形

## 6.3 选中框 (SelectedBox)

### 6.3.1 选中框管理器

**位置**: `packages/core/src/selected_box.ts`

**核心职责**:

- 计算选中图形的合并边界框
- 绘制选中框
- 绘制控制点
- 计算控制点位置

### 6.3.2 选中框显示

**显示条件**:

- 有图形被选中时显示
- 单个图形选中：显示该图形的边界框
- 多个图形选中：显示合并边界框

**样式**:

- **边框颜色**: `#1592fe` (蓝色)
- **边框宽度**: 1.2px
- **虚线样式**: 可选

### 6.3.3 控制点

**控制点类型**:

1. **8 个方向控制点**:
   - 上 (north)
   - 下 (south)
   - 左 (west)
   - 右 (east)
   - 左上 (northwest)
   - 右上 (northeast)
   - 左下 (southwest)
   - 右下 (southeast)
2. **旋转控制点**: 选中框上方
3. **特殊控制点**: 某些图形特有的控制点（如直线端点）

**控制点样式**:

- **大小**: 7px
- **填充**: `#fcfcfc` (浅灰色)
- **描边**: `#1592fe` (蓝色)
- **描边宽度**: 2px

**控制点交互**:

- **悬停**: 光标变为对应的调整光标
- **按下**: 开始变换操作
- **拖拽**: 执行变换
- **释放**: 完成变换

### 6.3.4 尺寸指示器

**显示位置**: 选中框上方或下方
**显示内容**: 宽度 × 高度

**样式**:

- **背景**: 半透明矩形
- **文字颜色**: `#fff` (白色)
- **字体**: 12px sans-serif
- **圆角**: 2px
- **内边距**: 上下 0px，左右 4px

**显示条件**:

- 尺寸大于 `sizeIndicatorMinSize` (10px) 时显示
- 距选中框距离: `sizeIndicatorOffset` (10px)

**精度**: `sizeIndicatorNumPrecision` (2 位小数)

## 6.4 变换操作

### 6.4.1 移动 (Move)

**操作方式**:

1. 拖拽选中框（非控制点区域）
2. 拖拽图形本身
3. 方向键移动

**实现**:

- **工具**: `tool_select_move.ts`
- **策略模式**: 使用策略模式处理不同情况

**约束**:

- **Shift**: 锁定水平或垂直方向
- **网格吸附**: 吸附到网格点
- **对象吸附**: 吸附到其他图形边缘

**快捷键移动**:

- **方向键**: 移动 1px（`smallNudge`）
- **Shift + 方向键**: 移动 10px（`bigNudge`）
- **连续移动**: 按住方向键连续移动（延迟 500ms）

### 6.4.2 缩放 (Resize)

**操作方式**:

- 拖拽选中框的控制点

**实现**:

- **工具**: `tool_select_resize.ts`
- **控制点**: 8 个方向控制点

**约束**:

- **Shift**: 等比例缩放
- **Alt**: 从中心缩放
- **网格吸附**: 吸附到网格点
- **对象吸附**: 吸附到其他图形边缘

**翻转**:

- 启用 `flipObjectsWhileResizing` 时，缩放可导致图形翻转
- 翻转时保持图形内容不变

**最小尺寸**:

- 防止图形缩放过小
- 最小宽度: 1px
- 最小高度: 1px

### 6.4.3 旋转 (Rotation)

**操作方式**:

- 拖拽旋转控制点（选中框上方）

**实现**:

- **工具**: `tool_select_rotation.ts`
- **旋转中心**: 选中框中心（可自定义）

**约束**:

- **Shift**: 锁定角度（15 度倍数，通过 `lockRotation` 配置）
- **角度计算**: 使用 `Math.atan2()` 计算角度

**旋转角度**:

- 存储为弧度
- 显示时转换为角度
- 支持负角度

### 6.4.4 变换计算

**变换矩阵**:

- 所有变换通过矩阵计算
- 使用 `@suika/geo` 包进行矩阵运算

**变换顺序**:

1. 缩放 (Scale)
2. 旋转 (Rotation)
3. 平移 (Translation)

**组合变换**:

- 支持多个变换的组合
- 通过矩阵乘法实现

## 6.5 选择操作策略模式

### 6.5.1 策略模式实现

**选择工具使用策略模式处理不同操作**:

1. **StrategyMove**: 移动策略
2. **StrategyResize**: 缩放策略
3. **StrategyRotation**: 旋转策略
4. **StrategyDrawSelection**: 框选策略

**位置**: `packages/core/src/tools/tool_select/`

### 6.5.2 策略切换

**切换条件**:

- 点击选中框内 → 移动策略
- 点击控制点 → 对应变换策略
- 点击空白区域 → 框选策略

## 6.6 碰撞检测

### 6.6.1 点选检测

**检测方法**:

- 使用 `Graphics.hitTest()` 方法
- 检测点是否在图形内部
- 考虑填充和描边

**检测顺序**:

- 从后往前遍历（Z-order）
- 返回最上层的图形

**容差**:

- `selectionHitPadding`: 4px
- 增加点选容差，便于选择

### 6.6.2 框选检测

**检测方法**:

- 计算图形边界框与选择矩形的相交/包含关系
- 使用 `@suika/geo` 包的几何计算函数

**检测模式**:

- **intersect**: 相交检测
- **contain**: 包含检测

### 6.6.3 优化策略

**空间索引**:

- 未来可考虑使用空间索引（如四叉树）优化
- 当前使用线性遍历

**脏区域检测**:

- 只检测可见区域的图形
- 只检测未锁定的图形

## 6.7 选择变化事件

### 6.7.1 事件类型

**itemsChange**: 选中项变化时触发

- 参数: `items: SuikaGraphics[]`
- 用途: 更新 UI（属性面板、图层面板等）

### 6.7.2 事件监听

**监听方式**:

```typescript
editor.selectedElements.on('itemsChange', (items) => {
  // 处理选中项变化
});
```

**使用场景**:

- 属性面板更新
- 图层面板高亮
- 工具栏按钮状态
- 对齐按钮启用/禁用

## 6.9 选择操作限制

### 6.9.1 锁定图形

**行为**:

- 锁定的图形无法被选中
- 锁定的图形无法被编辑
- 锁定的图形无法被删除

**例外**:

- 组内图形锁定后，组仍可被选中和编辑

### 6.9.2 隐藏图形

**行为**:

- 隐藏的图形无法被选中
- 隐藏的图形不参与框选检测
- 隐藏的图形不显示在图层面板（可选）

### 6.9.3 画板限制

**行为**:

- 画板内的图形受画板边界限制
- 移动画板内图形时，不能移出画板
- 缩放画板内图形时，不能超出画板

## 6.10 选择操作性能

### 6.10.1 性能优化

**优化策略**:

- 使用事件节流
- 批量更新
- 延迟渲染

**性能指标**:

- 选择操作响应时间: < 16ms
- 框选操作流畅度: 60 FPS

### 6.10.2 大量图形处理

**处理策略**:

- 只检测可见区域的图形
- 使用空间索引（未来优化）
- 限制框选检测范围
