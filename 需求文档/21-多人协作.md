## 21.3 实时同步

### 21.3.1 操作同步

**本地操作**:

1. 用户操作 → 编辑器更新
2. 编辑器变化 → SuikaBinding 监听
3. Yjs 事务 → 广播到其他用户

**远程操作**:

1. 收到 Yjs 更新
2. SuikaBinding 处理
3. 编辑器更新 → UI 刷新

### 21.3.2 同步流程

**编辑器 → 远程**:

```typescript
editor.doc.on('sceneChange', (ops: IChanges) => {
  yMap.transact(() => {
    // 添加新图形
    for (const [id, attrs] of ops.added) {
      yMap.set(id, attrs);
    }
    // 删除图形
    for (const id of ops.deleted) {
      yMap.delete(id);
    }
    // 更新图形
    for (const [id, attrs] of ops.update) {
      yMap.set(id, { ...yMap.get(id), ...attrs });
    }
  });
});
```

**远程 → 编辑器**:

```typescript
yMap.observe((event: YMapEvent) => {
  // 处理远程变化
  // 更新本地编辑器
});
```

**操作类型**:

- 插入操作

- 更新操作

### 21.4.2 冲突场景

**同时编辑**:

- 两人同时修改同一图形
- 自动合并更改
- 保持操作顺序

**网络延迟**:

- 操作乱序到达
- CRDT 重新排序
- 保证因果关系
