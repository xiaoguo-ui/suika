# 7. 属性面板详细需求

## 7.1 属性面板概述

### 7.1.1 面板位置

**位置**: 编辑器右侧
**宽度**: 240px
**高度**: 视口高度

### 7.1.2 面板组件

**位置**: `apps/suika/src/components/InfoPanel/`

**主要组件**:

- `InfoPanel`: 主面板容器
- `ElementsInfoCard`: 元素信息卡片
- `LayerInfoCard`: 图层信息卡片
- `FillCard`: 填充卡片
- `StrokeCard`: 描边卡片
- `AlignCard`: 对齐卡片
- `PaintCard`: 绘画属性卡片

## 7.2 元素信息卡片

### 7.2.1 基本信息

**显示内容**:

- **名称**: 图形对象名称 (`objectName`)
  - 可编辑输入框
  - 实时更新图形名称
- **位置**: X、Y 坐标
  - 显示世界坐标
  - 可编辑（未来功能）
- **尺寸**: 宽度、高度
  - 显示像素值
  - 可编辑（未来功能）
- **旋转**: 旋转角度
  - 显示角度值（度）
  - 可编辑（未来功能）

### 7.2.2 多选状态

**显示内容**:

- **选中数量**: "已选择 N 个图形"
- **混合值**: 某些属性显示 "多值" (mixed)
  - 填充: 如果选中图形的填充不同，显示 "多值"
  - 描边: 如果选中图形的描边不同，显示 "多值"
  - 其他属性同理

## 7.3 图层信息卡片

### 7.3.1 显示/隐藏

**功能**:

- 切换图形可见性
- 图标: 眼睛图标
- 状态: 显示/隐藏

**操作**:

- 点击切换可见性
- 快捷键: 右键菜单 → 显示/隐藏

### 7.3.2 锁定/解锁

**功能**:

- 锁定图形，防止误操作
- 图标: 锁定图标
- 状态: 锁定/解锁

**操作**:

- 点击切换锁定状态
- 快捷键: 右键菜单 → 锁定/解锁

**效果**:

- 锁定的图形无法被选中
- 锁定的图形无法被编辑
- 锁定的图形无法被删除

## 7.4 填充卡片 (FillCard)

### 7.4.1 填充显示

**显示方式**:

- 颜色预览框
- 颜色值显示（RGBA 或 HEX）
- 填充类型图标

### 7.4.2 填充类型

**纯色填充 (Solid)**:

- 显示颜色预览
- 显示颜色值（RGBA 或 HEX）
- 点击打开颜色选择器

**图片填充 (Image)**:

- 显示图片预览
- 显示图片 URL 或 base64
- 点击打开图片选择器

### 7.4.3 多填充支持

**显示**:

- 支持多个填充层
- 显示填充层列表
- 可添加/删除填充层

**操作**:

- 点击添加填充层
- 点击删除填充层
- 拖拽调整填充层顺序

### 7.4.4 颜色选择器

**组件**: `ColorPicker`

**类型**:

1. **SolidPicker**: 纯色选择器

   - RGB 滑块
   - Alpha 滑块
   - HEX 输入框
   - 颜色预设

2. **ImagePicker**: 图片选择器
   - 上传图片
   - 从 URL 加载
   - 从剪贴板粘贴

**位置**: `apps/suika/src/components/ColorPicker/`

## 7.5 描边卡片 (StrokeCard)

### 7.5.1 描边显示

**显示内容**:

- 描边颜色预览
- 描边宽度
- 描边类型

### 7.5.2 描边属性

**宽度**:

- 输入框: 数字输入
- 单位: 像素 (px)
- 范围: 0 - 1000px（可配置）

**颜色**:

- 同填充颜色选择器
- 支持纯色和图片描边

**样式**:

- 实线
- 虚线（未来功能）
- 点线（未来功能）

### 7.5.3 多描边支持

**显示**: 同多填充支持
**操作**: 同多填充操作

## 7.6 对齐卡片 (AlignCard)

### 7.6.1 对齐按钮

**显示条件**: 选中 2 个或更多图形时启用

**对齐类型**:

1. **左对齐** (Align Left)

   - 图标: `AlignLeft`
   - 快捷键: `Alt + A`
   - 功能: 所有选中图形左边缘对齐

2. **水平居中** (Align Horizontal Center)

   - 图标: `AlignHCenter`
   - 快捷键: `Alt + H`
   - 功能: 所有选中图形水平中心对齐

3. **右对齐** (Align Right)

   - 图标: `AlignRight`
   - 快捷键: `Alt + D`
   - 功能: 所有选中图形右边缘对齐

4. **上对齐** (Align Top)

   - 图标: `AlignTop`
   - 快捷键: `Alt + W`
   - 功能: 所有选中图形上边缘对齐

5. **垂直居中** (Align Vertical Center)

   - 图标: `AlignVCenter`
   - 快捷键: `Alt + V`
   - 功能: 所有选中图形垂直中心对齐

6. **下对齐** (Align Bottom)
   - 图标: `IconAlignBottom`
   - 快捷键: `Alt + S`
   - 功能: 所有选中图形下边缘对齐

### 7.6.2 对齐算法

**实现**: `packages/core/src/service/align_and_record.ts`

**对齐参考**:

- 计算所有选中图形的边界框
- 合并边界框
- 以合并边界框的对应边/中心为参考

**对齐操作**:

1. 计算每个图形需要移动的距离
2. 更新图形位置
3. 记录命令（支持撤销/重做）

### 7.6.3 对齐优化

**已对齐检测**:

- 如果图形已经对齐，不执行对齐操作
- 避免不必要的命令记录

## 7.9 属性更新机制

### 7.9.1 更新流程

```
用户操作
  ↓
UI 组件更新
  ↓
调用 Editor API
  ↓
更新图形属性
  ↓
记录命令
  ↓
触发场景变化事件
  ↓
重新渲染
```

### 7.9.2 批量更新

**场景**:

- 同时更新多个图形的属性
- 使用 Transaction 批量处理

**实现**:

```typescript
const transaction = new Transaction(editor);
for (const graphics of selectedGraphics) {
  transaction.update(graphics.id, { opacity: 0.5 });
}
transaction.commit('Update Opacity');
```

### 7.9.3 实时更新

**特性**:

- 属性修改立即生效
- 实时预览
- 实时渲染

## 7.10 属性面板状态管理

### 7.10.1 选中状态监听

**监听方式**:

```typescript
editor.selectedElements.on('itemsChange', (items) => {
  // 更新属性面板显示
});
```

**更新内容**:

- 选中项信息
- 属性值
- 启用/禁用状态

### 7.10.2 多选状态处理

**显示策略**:

- 所有选中图形共有的属性：显示值
- 选中图形不同的属性：显示 "多值" (mixed)
- 禁用某些操作（如对齐，需要至少 2 个图形）

### 7.10.3 空选状态

**显示内容**:

- "没有选中的图形"
- 禁用所有属性编辑
- 显示提示信息
