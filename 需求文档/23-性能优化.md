# 23. 性能优化详细需求

## 23.1 性能监控

### 23.1.1 PerfMonitor

**位置**: `packages/core/src/perf_monitor.ts`

**监控指标**:

- FPS (帧率)
- 渲染时间
- 内存使用
- 操作响应时间

### 23.1.2 性能面板

**显示位置**: 编辑器右上角

**显示内容**:

- 当前 FPS
- 平均 FPS
- 内存使用
- 渲染耗时

**配置开关**:

- `showPerfMonitor`: 是否显示性能监控

## 23.2 渲染优化

### 23.2.1 Canvas 渲染优化

**双缓冲**:

- 使用离屏 Canvas 渲染
- 减少屏幕闪烁
- 提高渲染质量

**脏区域渲染**:

- 只重绘变化区域
- 减少不必要的绘制
- 提高渲染效率

### 23.2.2 按需渲染

**渲染触发**:

- 图形变化时渲染
- 视图变化时渲染
- 避免过度渲染

**渲染节流**:

- 使用 `requestAnimationFrame`
- 限制渲染频率
- 避免性能浪费
