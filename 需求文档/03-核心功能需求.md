# 3. 核心功能需求

## 3.1 图形创建

### 3.1.1 支持的图形类型

#### 矩形 (Rect)

- **工具类型**: `tool_draw_rect`
- **快捷键**: `R`
- **功能特性**:
  - 支持圆角设置
  - 支持填充和描边
  - 支持变换（移动、缩放、旋转）
- **默认属性**:
  - 宽度: 100px
  - 高度: 100px
  - 圆角: 0

#### 椭圆 (Ellipse)

- **工具类型**: `tool_draw_ellipse`
- **快捷键**: `O`
- **功能特性**:
  - 支持填充和描边
  - 支持变换
- **默认属性**:
  - 宽度: 100px
  - 高度: 100px

#### 直线 (Line)

- **工具类型**: `tool_draw_line`
- **快捷键**: `L`
- **功能特性**:
  - 支持描边宽度设置
  - 支持描边颜色设置
  - 支持端点样式设置
- **默认属性**:
  - 描边宽度: 1px

#### 路径 (Path)

- **工具类型**: `tool_draw_path`
- **快捷键**: `P`
- **功能特性**:
  - 支持多段线绘制
  - 支持路径编辑（钢笔工具）
  - 支持控制点调整
- **默认属性**:
  - 描边宽度: 1px

#### 文本 (Text)

- **工具类型**: `tool_draw_text`
- **快捷键**: `T`
- **功能特性**:
  - 支持多行文本
  - 支持字体设置（字体族、大小、样式）
  - 支持文本颜色
  - 支持文本对齐
  - 内联编辑
- **默认属性**:
  - 字体大小: 12px
  - 字体族: sans-serif
  - 文本颜色: 黑色

#### 正多边形 (Regular Polygon)

- **工具类型**: `tool_draw_regular_polygon`
- **快捷键**: 无（通过菜单访问）
- **功能特性**:
  - 支持边数设置（3-12 边）
  - 支持填充和描边
  - 支持变换
- **默认属性**:
  - 边数: 3（三角形）
  - 宽度: 100px
  - 高度: 100px

#### 星形 (Star)

- **工具类型**: `tool_draw_star`
- **快捷键**: `S`
- **功能特性**:
  - 支持角数设置（3-12 角）
  - 支持内半径比例设置
  - 支持填充和描边
  - 支持变换
- **默认属性**:
  - 角数: 5
  - 内半径比例: 0.3819660246372223
  - 宽度: 100px
  - 高度: 100px

#### 画板 (Frame)

- **工具类型**: `tool_draw_frame`
- **快捷键**: `F`
- **功能特性**:
  - 作为容器使用
  - 支持子图形嵌套
  - 支持自动调整大小 (`resizeToFit`)
  - 支持填充颜色设置
- **默认属性**:
  - 宽度: 400px
  - 高度: 300px
  - 填充: 白色

#### 图片 (Image)

- **工具类型**: `tool_draw_img`
- **快捷键**: `I`
- **功能特性**:
  - 支持图片上传
  - 支持图片裁剪
  - 支持图片变换
  - 支持从剪贴板粘贴图片
- **默认属性**:
  - 宽度: 图片原始宽度
  - 高度: 图片原始高度

### 3.1.2 图形创建流程

1. **选择工具**: 用户从工具栏选择绘图工具
2. **鼠标按下**: 在画布上按下鼠标，记录起始点
3. **鼠标拖拽**: 拖拽鼠标，实时预览图形
4. **鼠标释放**: 释放鼠标，确认创建图形
5. **图形添加**: 将图形添加到场景图
6. **命令记录**: 记录到命令栈，支持撤销

### 3.1.3 图形创建约束

- **最小尺寸**: 图形创建时如果拖拽距离过小，使用默认尺寸
- **Shift 约束**: 按住 Shift 键可创建正方形/圆形
- **吸附功能**: 启用网格吸附时，创建点会吸附到网格
- **画板限制**: 图形创建在画板内时，受画板边界限制

## 3.2 图形编辑

### 3.2.1 选择操作

#### 单选

- **操作**: 点击图形
- **效果**: 选中单个图形，显示选中框和控制点

#### 多选

- **操作方式**:
  - Shift + 点击: 添加/移除选中项
  - 框选: 拖拽选择区域
- **效果**: 显示多个图形的合并选中框

#### 框选

- **操作**: 在空白区域拖拽
- **选择模式**:
  - `intersect`: 与选区相交即选中（默认）
  - `contain`: 完全包含在选区内才选中
- **可配置**: 通过 `setting.selectionMode` 配置

#### 全选

- **快捷键**: `Cmd/Ctrl + A`
- **效果**: 选中所有可见且未锁定的图形

### 3.2.2 变换操作

#### 移动

- **操作**: 拖拽选中框或图形本身
- **约束**:
  - Shift: 锁定水平或垂直方向
  - 网格吸附: 吸附到网格点
  - 对象吸附: 吸附到其他图形边缘
- **快捷键**: 方向键移动（1px），Shift + 方向键（10px）

#### 缩放

- **操作**: 拖拽选中框的控制点
- **控制点**:
  - 8 个方向控制点（上、下、左、右、左上、右上、左下、右下）
  - 宽度控制点（仅用于特定图形）
- **约束**:
  - Shift: 等比例缩放
  - Alt: 从中心缩放
  - 网格吸附: 吸附到网格点
- **翻转**: 启用 `flipObjectsWhileResizing` 时，缩放可导致翻转

#### 旋转

- **操作**: 拖拽旋转控制点（选中框上方）
- **约束**:
  - Shift: 锁定角度（15 度倍数，通过 `lockRotation` 配置）
- **中心点**: 可自定义旋转中心

#### 变换矩阵

- **格式**: 3x3 矩阵，存储为 6 元素数组

  ```
  [a, b, c, d, tx, ty]
  对应矩阵:
  | a  c  tx |
  | b  d  ty |
  | 0  0  1  |
  ```

- **计算**: 使用 `@suika/geo` 包进行矩阵运算

### 3.2.3 属性编辑

#### 基础属性

- **名称**: 图形对象名称（`objectName`）
- **尺寸**: 宽度、高度（受变换影响）
- **位置**: X、Y 坐标（世界坐标）
- **旋转**: 旋转角度（弧度）
- **透明度**: 0-1 范围

#### 填充属性

- **类型**:
  - 纯色 (Solid): RGBA 颜色值
  - 图片 (Image): 图片 URL 或 base64
- **多填充**: 支持多个填充层（数组）
- **编辑**: 通过属性面板的颜色选择器编辑

#### 描边属性

- **类型**: 同填充类型
- **宽度**: 描边宽度（像素）
- **多描边**: 支持多个描边层（数组）
- **端点样式**: 支持多种端点样式

#### 可见性

- **显示/隐藏**: 切换图形可见性
- **快捷键**: 右键菜单或图层面板
- **效果**: 隐藏的图形不渲染，但仍参与布局计算

#### 锁定

- **锁定/解锁**: 锁定图形，防止误操作
- **快捷键**: 右键菜单或图层面板
- **效果**: 锁定的图形无法被选中和编辑

### 3.2.4 路径编辑

#### 路径选择工具

- **工具类型**: `tool_path_select`
- **激活方式**: 双击路径图形
- **功能**:
  - 选择路径节点
  - 移动节点
  - 调整控制点（贝塞尔曲线）
  - 添加/删除节点
  - 转换节点类型（直线/曲线）

#### 路径编辑模式

- **节点显示**: 显示所有路径节点和控制点
- **选中节点**: 高亮选中的节点
- **控制点**: 显示贝塞尔曲线的控制点
- **退出**: ESC 键或点击空白区域

## 3.3 文本编辑

### 3.3.1 文本创建

- **工具**: 文本工具 (`T`)
- **操作**: 点击画布创建文本输入框
- **默认文本**: "Text" 或空文本

### 3.3.2 文本编辑

- **激活**: 双击文本图形
- **编辑模式**:
  - 显示文本输入框
  - 支持文本选择
  - 支持光标定位
  - 支持多行文本
- **退出**: ESC 键或点击空白区域

### 3.3.3 文本属性

- **字体族**: 字体名称（如 'Arial', 'sans-serif'）
- **字体大小**: 像素值
- **字体样式**: 粗体、斜体等
- **文本对齐**: 左对齐、居中、右对齐
- **行高**: 行间距
- **字间距**: 字符间距

### 3.3.4 文本渲染

- **测量**: 使用 Canvas `measureText()` API
- **换行**: 自动换行（根据宽度）
- **选择**: 支持文本范围选择
- **光标**: 显示编辑光标

## 3.4 画布操作

### 3.4.1 无限画布

- **特性**: 画布尺寸不受限制
- **坐标范围**: 理论上无限制（实际受 JavaScript 数值精度限制）
- **滚动**: 通过平移和缩放访问不同区域

### 3.4.2 画布平移

- **工具**: 抓手工具 (`H` 或空格键)
- **操作**: 拖拽画布
- **快捷键**: 空格键临时切换为抓手工具
- **效果**: 改变视口位置，不改变图形位置

### 3.4.3 画布缩放

- **缩放方式**:
  - 鼠标滚轮: 缩放（可配置方向反转）
  - 缩放工具: 工具栏缩放按钮
  - 快捷键: `Cmd/Ctrl + +/-`
- **缩放级别**: 0.015625 (1.5625%) - 256 (25600%)
- **缩放步长**: 0.2325（约 23%）
- **缩放中心**: 以鼠标位置为中心缩放

### 3.4.4 缩放操作

- **适应画布**: 缩放至显示所有图形
- **适应选中**: 缩放至显示选中图形
- **缩放至**: 50%, 100%, 200% 等预设级别
- **缩放输入**: 手动输入缩放百分比

## 3.5 视图功能

### 3.5.1 像素网格

- **显示条件**: 缩放级别 >= 8 (800%)
- **网格间距**: 1 像素
- **网格颜色**: `#cccccc55` (半透明灰色)
- **配置**: 可通过设置开启/关闭

### 3.5.2 标尺

- **位置**: 画布顶部和左侧
- **宽度**: 20px
- **刻度**: 根据缩放级别动态显示
- **颜色**:
  - 背景: 白色
  - 边框: `#e6e6e6`
  - 刻度: `#c1c1c1`
- **配置**: 可通过设置开启/关闭

### 3.5.3 参考线

- **类型**:
  - 水平参考线
  - 垂直参考线
- **显示**: 当图形对齐时自动显示
- **颜色**: `#f14f30ee` (红色半透明)
- **吸附容差**: 4px（可配置）

### 3.5.4 选中框

- **边框颜色**: `#1592fe` (蓝色)
- **边框宽度**: 1.2px
- **控制点**: 8 个方向 + 旋转控制点
- **控制点样式**:
  - 填充: `#fcfcfc`
  - 描边: `#1592fe`
  - 大小: 7px
- **尺寸指示器**: 显示图形尺寸信息

## 3.6 性能要求

### 3.6.1 渲染性能

- **目标 FPS**: 60 FPS
- **渲染优化**:
  - RAF 节流
  - 脏区域检测
  - 按需渲染
- **性能监控**: 可选的性能监控面板

### 3.6.2 响应性能

- **交互延迟**: < 16ms (60 FPS)
- **缩放动画**: 平滑过渡
- **拖拽响应**: 实时反馈

### 3.6.3 内存管理

- **图片管理**: 图片缓存和释放
- **事件清理**: 组件销毁时清理事件监听
- **对象池**: 考虑使用对象池优化（未来优化）
