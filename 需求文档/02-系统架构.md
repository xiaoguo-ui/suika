# 2. 系统架构

## 2.1 整体架构

Suika 编辑器采用分层架构设计，核心编辑器逻辑与 UI 层分离，支持多种应用场景。

### 2.1.1 架构层次

```
┌─────────────────────────────────────────┐
│          UI Layer (React)               │
│  ┌──────────┐  ┌──────────┐  ┌──────┐ │
│  │ Header   │  │  Canvas  │  │Panel │ │
│  └──────────┘  └──────────┘  └──────┘ │
└─────────────────────────────────────────┘
┌─────────────────────────────────────────┐
│      Editor Core (@suika/core)          │
│  ┌──────────┐  ┌──────────┐  ┌──────┐ │
│  │  Tools   │  │ Graphics  │  │Scene │ │
│  └──────────┘  └──────────┘  └──────┘ │
└─────────────────────────────────────────┘
┌─────────────────────────────────────────┐
│      Foundation Libraries               │
│  ┌──────────┐  ┌──────────┐  ┌──────┐ │
│  │  Geo     │  │ Common   │  │Icons │ │
│  └──────────┘  └──────────┘  └──────┘ │
└─────────────────────────────────────────┘
```

### 2.1.2 包依赖关系

```
@suika/suika (单用户版)
├── @suika/core (编辑器核心)
│   ├── @suika/geo (几何计算)
│   └── @suika/common (通用工具)
├── @suika/components (UI组件)
├── @suika/icons (图标)
└── React生态系统

@suika/suika-multiplayer (多人协作版)
├── @suika/suika (继承所有依赖)
├── yjs (CRDT)
├── @hocuspocus/provider (协作提供者)
└── y-websocket (WebSocket)
```

## 2.2 核心模块

### 2.2.1 SuikaEditor 类

编辑器的主入口类，负责协调各个模块。

**位置**: `packages/core/src/editor.ts`

**核心职责**:

- 初始化和管理所有子模块
- 提供统一的 API 接口
- 管理编辑器生命周期

**主要属性**:

```typescript
class SuikaEditor {
  containerElement: HTMLDivElement; // 画板容器
  canvasElement: HTMLCanvasElement; // 画布元素
  ctx: CanvasRenderingContext2D; // 画布上下文

  doc: SuikaDocument; // 文档对象
  sceneGraph: SceneGraph; // 场景图
  toolManager: ToolManager; // 工具管理器
  commandManager: CommandManager; // 命令管理器
  viewportManager: ViewportManager; // 视口管理器
  zoomManager: ZoomManager; // 缩放管理器
  selectedElements: SelectedElements; // 选中元素管理器
  clipboard: ClipboardManager; // 剪贴板管理器
  // ... 更多模块
}
```

### 2.2.2 场景图 (SceneGraph)

管理所有图形对象的树形结构。

**位置**: `packages/core/src/scene/scene_graph.ts`

**核心功能**:

- 图形对象的增删改查
- 图形树的构建和维护
- 图形序列化和反序列化
- 场景变化事件通知

**数据结构**:

```
Document (根节点)
└── Canvas
    └── Frame/Graphics (图形对象)
        └── Graphics (子图形)
```

### 2.2.3 文档对象 (SuikaDocument)

文档的顶层容器，管理画布和所有图形。

**位置**: `packages/core/src/graphics/document.ts`

**核心功能**:

- 管理画布对象
- 提供图形查找接口
- 管理文档级设置

### 2.2.4 工具管理器 (ToolManager)

管理所有工具的状态切换和交互。

**位置**: `packages/core/src/tools/tool_manager.ts`

**核心功能**:

- 工具注册和切换
- 工具快捷键绑定
- 工具状态管理
- 工具拖拽状态检测

### 2.2.5 命令管理器 (CommandManager)

实现撤销/重做功能。

**位置**: `packages/core/src/commands/command_manager.ts`

**核心功能**:

- 命令栈管理（撤销栈、重做栈）
- 命令执行和回滚
- 批量命令支持
- 命令状态变化通知

### 2.2.6 视口管理器 (ViewportManager)

管理画布的视口变换。

**位置**: `packages/core/src/viewport_manager.ts`

**核心功能**:

- 视口坐标与场景坐标转换
- 视口大小管理
- 视口中心点计算

### 2.2.7 缩放管理器 (ZoomManager)

管理画布的缩放级别。

**位置**: `packages/core/src/zoom_manager.ts`

**核心功能**:

- 缩放级别管理（0.015625 - 256）
- 缩放动画
- 缩放到指定区域
- 缩放步长控制

### 2.2.8 选中元素管理器 (SelectedElements)

管理当前选中的图形对象。

**位置**: `packages/core/src/selected_elements.ts`

**核心功能**:

- 选中状态管理
- 选中框绘制
- 选中元素变化事件
- 多选支持

## 2.3 图形系统

### 2.3.1 图形基类 (SuikaGraphics)

所有图形对象的基类。

**位置**: `packages/core/src/graphics/graphics/graphics.ts`

**核心功能**:

- 图形属性管理
- 图形变换计算
- 图形渲染
- 碰撞检测
- 边界框计算

**图形类型**:

- `SuikaRect`: 矩形（支持圆角）
- `SuikaEllipse`: 椭圆
- `SuikaLine`: 直线
- `SuikaPath`: 路径
- `SuikaText`: 文本
- `SuikaRegularPolygon`: 正多边形
- `SuikaStar`: 星形
- `SuikaFrame`: 画板/组
- `SuikaCanvas`: 画布
- `SuikaDocument`: 文档

### 2.3.2 图形属性 (GraphicsAttrs)

图形的基础属性定义。

**位置**: `packages/core/src/graphics/graphics/graphics_attrs.ts`

**属性结构**:

```typescript
interface GraphicsAttrs {
  type?: GraphicsType; // 图形类型
  id: string; // 唯一标识
  objectName: string; // 对象名称
  width: number; // 宽度
  height: number; // 高度
  transform: IMatrixArr; // 变换矩阵
  opacity?: number; // 透明度
  fill?: IPaint[]; // 填充
  stroke?: IPaint[]; // 描边
  strokeWidth?: number; // 描边宽度
  visible?: boolean; // 可见性
  lock?: boolean; // 锁定状态
  parentIndex?: IParentIndex; // 父级索引
}
```

## 2.4 事件系统

### 2.4.1 事件管理器

**HostEventManager**: 管理宿主环境事件（鼠标、键盘、滚轮等）
**位置**: `packages/core/src/host_event_manager/host_event_manager.ts`

**MouseEventManager**: 鼠标事件管理器
**位置**: `packages/core/src/host_event_manager/mouse_event_manager.ts`

**CommandKeyBinding**: 命令快捷键绑定
**位置**: `packages/core/src/host_event_manager/command_key_binding.ts`

### 2.4.2 事件流

```
用户操作
  ↓
浏览器事件 (MouseEvent, KeyboardEvent)
  ↓
HostEventManager (事件分发)
  ↓
ToolManager (工具处理)
  ↓
Graphics (图形更新)
  ↓
SceneGraph (场景更新)
  ↓
Canvas 渲染
```

## 2.5 坐标系统

### 2.5.1 坐标类型

1. **屏幕坐标 (Screen Coordinates)**: 浏览器窗口的像素坐标
2. **视口坐标 (Viewport Coordinates)**: 画布容器的坐标
3. **场景坐标 (Scene Coordinates)**: 图形在世界坐标系中的坐标

### 2.5.2 坐标转换

**位置**: `packages/common/src/common.ts`

- `viewportCoordsToSceneUtil`: 视口坐标 → 场景坐标
- `sceneCoordsToViewportUtil`: 场景坐标 → 视口坐标

## 2.6 渲染系统

### 2.6.1 渲染流程

```
Editor.render()
  ↓
SceneGraph.render()
  ↓
遍历图形树
  ↓
Graphics.draw() (每个图形绘制)
  ↓
Canvas 2D API
```

### 2.6.2 渲染优化

- RAF 节流 (`rafThrottle`)
- 脏区域检测
- 按需渲染

## 2.7 数据持久化

### 2.7.1 单用户版

- **自动保存**: 使用 localStorage 保存图纸数据
- **存储键**: `suika-paper`
- **数据格式**: JSON (IEditorPaperData)

### 2.7.2 多人协作版

- **实时同步**: 使用 Yjs 进行 CRDT 同步
- **WebSocket**: 通过 Hocuspocus 连接服务器
- **数据存储**: Y.Map 存储图形数据

## 2.8 UI 组件架构

### 2.8.1 组件结构

```
Editor (主组件)
├── Header (顶部栏)
│   ├── Title (标题)
│   └── Toolbar (工具栏)
├── LayerPanel (左侧图层面板)
├── Canvas (画布区域)
├── InfoPanel (右侧属性面板)
└── ContextMenu (右键菜单)
```

### 2.8.2 状态管理

- 使用 React Context 管理编辑器实例
- 使用事件系统进行组件间通信
- 使用 React Hooks 管理组件状态

## 2.9 扩展性设计

### 2.9.1 工具扩展

- 通过 `ToolManager.registerToolCtor()` 注册新工具
- 实现 `ITool` 接口
- 支持工具快捷键配置

### 2.9.2 图形扩展

- 继承 `SuikaGraphics` 基类
- 实现 `draw()` 方法
- 在 `graphCtorMap` 中注册

### 2.9.3 命令扩展

- 实现 `ICommand` 接口
- 通过 `CommandManager.execute()` 执行
- 支持撤销/重做
