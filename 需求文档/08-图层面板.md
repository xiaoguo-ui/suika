# 8. 图层面板详细需求

## 8.1 图层面板概述

### 8.1.1 面板位置

**位置**: 编辑器左侧
**宽度**: 240px
**高度**: 视口高度

### 8.1.2 面板组件

**位置**: `apps/suika/src/components/LayerPanel/`

**主要组件**:

- `LayerPanel`: 主面板容器
- `LayerTree`: 图层树组件
- `LayerItem`: 图层项组件
- `LayerIcon`: 图层图标组件

## 8.2 图层树结构

### 8.2.1 树形结构

**结构层次**:

```
Document (文档)
└── Canvas (画布)
    ├── Frame/Graphics (图形对象)
    │   └── Graphics (子图形)
    └── Frame/Graphics
```

**显示方式**:

- 树形列表
- 支持展开/折叠
- 缩进显示层级关系

### 8.2.2 图层顺序

**顺序规则**:

- 使用 Fractional Indexing 算法管理顺序
- 后创建的图形在上层
- 支持拖拽调整顺序

**显示顺序**:

- 列表从上到下对应画布从后到前
- 或：列表从上到下对应画布从前到后（可配置）

## 8.3 图层项 (LayerItem)

### 8.3.1 显示内容

**图层项显示**:

- **图标**: 图形类型图标
  - 矩形图标
  - 椭圆图标
  - 文本图标
  - 路径图标
  - 等等
- **名称**: 图形对象名称 (`objectName`)
- **状态图标**:
  - 眼睛图标（可见/隐藏）
  - 锁定图标（锁定/解锁）

### 8.3.2 图层图标

**图标类型**:

- `RectIcon`: 矩形
- `EllipseIcon`: 椭圆
- `LineIcon`: 直线
- `PathIcon`: 路径
- `TextIcon`: 文本
- `PolygonIcon`: 多边形
- `StarIcon`: 星形
- `FrameIcon`: 画板/组
- `ImageIcon`: 图片

**位置**: `apps/suika/src/components/LayerPanel/LayerTree/LayerIcon.tsx`

### 8.3.3 图层名称

**显示**:

- 显示 `objectName` 属性
- 如果为空，显示默认名称（如 "Rectangle", "Ellipse"）

**编辑**:

- 双击进入编辑模式
- 输入新名称
- 回车确认，ESC 取消

### 8.3.4 状态指示

**可见性**:

- 眼睛图标：显示/隐藏
- 点击切换可见性
- 隐藏的图形图标变灰

**锁定状态**:

- 锁定图标：锁定/解锁
- 点击切换锁定状态
- 锁定的图形图标变灰

## 8.4 图层交互

### 8.4.1 选择图层

**操作方式**:

- 点击图层项
- 选中对应图形
- 显示选中框

**多选**:

- Shift + 点击：多选
- Ctrl/Cmd + 点击：多选

### 8.4.2 展开/折叠

**操作方式**:

- 点击展开/折叠图标
- 展开/折叠子图层

**显示规则**:

- 有子图层的图形显示展开/折叠图标
- 组（Frame）和画板可展开

### 8.4.3 拖拽排序

**操作方式**:

- 拖拽图层项
- 调整图层顺序
- 改变 Z-order

**限制**:

- 不能拖拽到锁定的图形内
- 不能拖拽锁定的图形

### 8.4.4 右键菜单

**菜单项**:

- 显示/隐藏
- 锁定/解锁
- 复制
- 删除
- 创建编组
- 取消编组
- 上移一层
- 下移一层
- 移到顶部
- 移到底部

## 8.7 图层高亮

### 8.7.1 悬停高亮

**功能**:

- 鼠标悬停在图层项上时
- 在画布上高亮对应图形
- 显示图形边框

**配置**:

- `highlightLayersOnHover`: 开启/关闭
- 高亮颜色: `#1592fe` (蓝色)
- 高亮宽度: 2px

### 8.7.2 选中高亮

**功能**:

- 选中的图层项高亮显示
- 背景色变化
- 文字加粗（可选）

## 8.8 图层操作

### 8.8.1 显示/隐藏

**操作**:

- 点击眼睛图标
- 右键菜单 → 显示/隐藏
- 快捷键: 右键菜单

**效果**:

- 隐藏的图形不渲染
- 隐藏的图形不参与选择
- 隐藏的图形不参与碰撞检测

### 8.8.2 锁定/解锁

**操作**:

- 点击锁定图标
- 右键菜单 → 锁定/解锁
- 快捷键: 右键菜单

**效果**:

- 锁定的图形无法被选中
- 锁定的图形无法被编辑
- 锁定的图形无法被删除

### 8.8.3 复制图层

**操作**:

- 右键菜单 → 复制
- 快捷键: `Cmd/Ctrl + C`

**效果**:

- 复制图形到剪贴板
- 可粘贴到其他位置

### 8.8.4 删除图层

**操作**:

- 右键菜单 → 删除
- 快捷键: `Delete` 或 `Backspace`

**效果**:

- 从场景图中移除图形
- 记录命令（支持撤销）

### 8.8.5 创建编组

**操作**:

- 选中多个图层
- 右键菜单 → 创建编组
- 快捷键: `Cmd/Ctrl + G`

**效果**:

- 创建 Frame 容器
- 将选中图形移入容器
- 自动调整容器大小

### 8.8.6 取消编组

**操作**:

- 选中组
- 右键菜单 → 取消编组
- 快捷键: `Cmd/Ctrl + Shift + G`

**效果**:

- 将组内图形移出
- 删除组容器
- 保持图形位置不变

## 8.9 图层排序

### 8.9.1 排序算法

**算法**: Fractional Indexing

**实现**:

- 使用 `fractional-indexing` 库
- 生成排序键
- 支持任意位置插入

**位置**: `packages/core/src/service/arrange_and_record.ts`

### 8.9.2 排序操作

**上移一层** (Forward):

- 快捷键: `Cmd/Ctrl + ]`
- 功能: 在当前父容器内上移一层

**下移一层** (Backward):

- 快捷键: `Cmd/Ctrl + [`
- 功能: 在当前父容器内下移一层

**移到顶部** (Front):

- 快捷键: `]`
- 功能: 移到当前父容器最上层

**移到底部** (Back):

- 快捷键: `[`
- 功能: 移到当前父容器最下层

### 8.9.3 排序限制

**限制规则**:

- 不能移到锁定的图形内
- 不能移到隐藏的图形内
- 组内图形不能移到组外

## 8.10 图层类型

### 8.10.1 图形类型

**支持的类型**:

- Rect (矩形)
- Ellipse (椭圆)
- Line (直线)
- Path (路径)
- Text (文本)
- RegularPolygon (正多边形)
- Star (星形)
- Frame (画板/组)
- Image (图片)

### 8.10.2 特殊类型

**画板 (Frame)**:

- 作为容器使用
- 可包含子图形
- 支持自动调整大小

**组 (Group)**:

- 使用 Frame 实现
- `isGroup()` 方法判断是否为组
- 可通过 `resizeToFit` 属性区分
