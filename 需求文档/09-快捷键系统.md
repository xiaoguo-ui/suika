# 9. 快捷键系统详细需求

## 9.1 快捷键系统概述

### 9.1.1 快捷键管理器 (KeyBindingManager)

**位置**: `packages/core/src/key_binding_manager.ts`

**核心职责**:

- 注册和管理所有快捷键
- 处理键盘事件
- 区分 Mac 和 Windows 快捷键
- 检查快捷键冲突
- 提供快捷键启用/禁用机制

### 9.1.2 快捷键绑定接口

```typescript
interface IKeyBinding {
  key: IKey | IKey[]; // Mac/其他系统快捷键
  winKey?: IKey | IKey[]; // Windows 快捷键
  actionName: string; // 动作名称（用于日志）
  action: (e: KeyboardEvent) => void; // 动作回调
  when?: (ctx: IWhenCtx) => boolean; // 启用条件
}
```

### 9.1.3 快捷键键码格式

**键码格式**: `KeyCode` 格式（如 `KeyZ`, `KeyA`）

**修饰键**:

- `metaKey`: Command 键 (Mac) / Windows 键 (Windows)
- `ctrlKey`: Control 键
- `altKey`: Option 键 (Mac) / Alt 键 (Windows)
- `shiftKey`: Shift 键

## 9.9 快捷键冲突处理

### 9.9.1 冲突检测

**检测时机**:

- 注册快捷键时检测
- 打印警告信息

**处理策略**:

- 后注册的快捷键覆盖先注册的
- 打印冲突警告

### 9.9.2 优先级规则

**优先级**:

1. 工具快捷键（最高优先级）
2. 命令快捷键
3. 其他快捷键

**冲突解决**:

- 高优先级快捷键优先
- 低优先级快捷键被忽略

## 9.10 快捷键启用条件

### 9.10.1 When 函数

**用途**: 控制快捷键的启用条件

**示例**:

```typescript
when: (ctx) => !ctx.isToolDragging;
```

**上下文对象**:

```typescript
interface IWhenCtx {
  isToolDragging: boolean; // 是否正在拖拽
}
```

### 9.10.2 常见条件

**非拖拽状态**:

- 大多数命令快捷键在非拖拽状态下生效
- 防止拖拽时误触发命令

**文本编辑状态**:

- 文本编辑时禁用全局快捷键
- 使用标准文本编辑快捷键

**输入框状态**:

- 在输入框中时禁用全局快捷键
- 使用标准输入快捷键

## 9.11 快捷键系统架构

### 9.11.1 事件流

```
键盘事件 (KeyboardEvent)
  ↓
KeyBindingManager.handleAction()
  ↓
检查快捷键匹配
  ↓
检查启用条件 (when)
  ↓
执行动作 (action)
  ↓
阻止默认行为 (preventDefault)
```

### 9.11.2 平台检测

**检测方式**:

- 使用 `isWindows()` 函数检测操作系统
- 根据平台选择对应的快捷键配置

**位置**: `packages/common/src/common.ts`

### 9.11.3 快捷键日志

**日志功能**:

- 快捷键触发时打印日志
- 格式: `[快捷键] => 动作名称`
- 用于调试和开发

## 9.12 快捷键扩展

### 9.12.1 注册新快捷键

**方式**:

```typescript
editor.keybindingManager.register({
  key: { metaKey: true, keyCode: 'KeyX' },
  winKey: { ctrlKey: true, keyCode: 'KeyX' },
  actionName: 'My Action',
  action: () => {
    // 执行动作
  },
  when: (ctx) => !ctx.isToolDragging,
});
```

### 9.12.2 取消注册快捷键

**方式**:

```typescript
const token = editor.keybindingManager.register({...});
editor.keybindingManager.unregister(token);
```

## 9.14 特殊键处理

### 9.14.1 Alt 键处理

**特殊处理**:

- Windows 系统下，Alt 键会触发浏览器菜单栏
- 需要 `preventDefault()` 阻止默认行为

### 9.14.2 输入框处理

**处理方式**:

- 检测事件目标是否为输入框
- 输入框中不处理全局快捷键
- 文本编辑器输入框例外

### 9.14.3 组合键处理

**处理方式**:

- 支持多修饰键组合
- 支持修饰键 + 普通键组合
- 不支持多个普通键组合
