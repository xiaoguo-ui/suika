# 18. 标尺系统详细需求

## 18.1 标尺系统概述

### 18.1.1 标尺管理器 (Ruler)

**位置**: `packages/core/src/ruler.ts`

**核心职责**:

- 管理标尺显示
- 计算刻度位置
- 处理标尺交互
- 提供测量功能

### 18.1.2 标尺位置

**水平标尺**:

- 位置: 编辑器顶部
- 宽度: 编辑器宽度
- 高度: 20px

**垂直标尺**:

- 位置: 编辑器左侧
- 高度: 编辑器高度
- 宽度: 20px

## 18.2 标尺显示

### 18.2.1 标尺样式

**背景**:

- 颜色: `#fff` (白色)
- 边框: `#e6e6e6`

**刻度线**:

- 主刻度: `#c1c1c1`
- 长度: 4px

**数字标签**:

- 字体: 12px sans-serif
- 颜色: `#333`
- 对齐: 居中

### 18.2.2 标尺可见性

**配置项**:

- `enableRuler`: 是否显示标尺
- 默认值: false

**切换方式**:

- 设置面板切换
- 快捷键切换（未来功能）

## 18.3 刻度计算

### 18.3.1 刻度算法

**基于缩放级别**:

- 缩放越大，刻度越密集
- 动态调整刻度间隔

**最小步长**:

- `minStepInViewport`: 视口最小步长（默认 50px）
- 根据缩放级别调整

### 18.3.2 刻度间隔

**计算公式**:

```typescript
// 根据视口步长计算世界坐标步长
const worldStep = minStepInViewport / zoom;

// 标准化到合适的值
const normalizedStep = getClosestPowerOf10(worldStep);

// 调整为易读的值 (1, 2, 5, 10, 20, 50, 100, ...)
const niceStep = getNiceNumber(normalizedStep);
```

### 18.3.3 刻度类型

**主刻度**:

- 显示数字标签
- 较长刻度线
- 规则间隔

**次刻度**:

- 不显示标签
- 较短刻度线
- 主刻度间的细分

## 18.5 标尺交互

### 18.5.1 创建参考线

**操作方式**:

- 从标尺拖拽创建参考线
- 点击标尺位置创建

**拖拽流程**:

1. 在标尺上按下鼠标
2. 拖拽到画布中
3. 显示预览线
4. 释放创建参考线

### 18.5.2 标尺缩放

**缩放反馈**:

- 标尺随画布缩放更新
- 实时调整刻度密度
- 保持坐标准确性

### 18.5.3 标尺选择

**选择区域**:

- 点击标尺选择对应位置
- 显示当前位置高亮

**鼠标悬停**:

## 18.7 标尺配置

### 18.7.1 显示设置

**配置项**:

- `enableRuler`: 显示标尺
- `rulerWidth`: 标尺宽度（默认 20px）
- `rulerBgColor`: 背景颜色
- `rulerStroke`: 边框颜色
- `rulerMarkStroke`: 刻度颜色

### 18.7.2 刻度设置

**配置项**:

- `minStepInViewport`: 最小视口步长
- `rulerMarkSize`: 刻度长度

### 18.7.3 单位设置

**支持单位**:

- 像素 (px)
- 厘米 (cm) - 未来
- 毫米 (mm) - 未来
- 英寸 (inch) - 未来
