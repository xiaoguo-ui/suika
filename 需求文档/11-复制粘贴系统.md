# 11. 复制粘贴系统详细需求

## 11.1 剪贴板管理器概述

### 11.1.1 剪贴板管理器 (ClipboardManager)

**位置**: `packages/core/src/clipboard.ts`

**核心职责**:

- 处理复制操作
- 处理粘贴操作
- 管理剪贴板数据格式
- 支持跨画布复制粘贴
- 支持图片粘贴

### 11.1.2 剪贴板数据格式

**JSON 格式**:

```json
{
  "appVersion": "suika-editor_0.0.2",
  "paperId": "clipboard",
  "data": [
    {
      "type": "Rect",
      "id": "...",
      "objectName": "..."
      // ... 图形属性
    }
  ]
}
```

## 11.2 复制操作

### 11.2.1 复制流程

1. 检查是否有选中的图形
2. 序列化选中图形数据
3. 转换为剪贴板格式
4. 写入系统剪贴板（文本格式）
5. 记录复制操作

### 11.2.2 复制快捷键

**Mac**: `Cmd + C`
**Windows**: `Ctrl + C`

**实现位置**: `packages/core/src/host_event_manager/command_key_binding.ts`

### 11.2.3 复制内容

**包含内容**:

- 图形属性数据
- 图形变换信息
- 图形父子关系
- 图形样式信息

**排除内容**:

- 图形 ID（粘贴时生成新 ID）
- 父级索引（粘贴时重新计算）

### 11.2.4 坐标转换

**转换规则**:

- 将图形从世界坐标转换为相对坐标
- 记录复制时的参考点
- 粘贴时使用新的参考点

## 11.3 粘贴操作

### 11.3.1 粘贴流程

1. 从系统剪贴板读取数据
2. 解析 JSON 数据
3. 验证数据格式
4. 生成新的图形 ID
5. 计算粘贴位置
6. 创建图形对象
7. 添加到场景图
8. 选中新粘贴的图形
9. 记录命令（支持撤销）

### 11.3.2 粘贴快捷键

**Mac**: `Cmd + V`
**Windows**: `Ctrl + V`

**实现位置**: `packages/core/src/host_event_manager/command_key_binding.ts`

### 11.3.3 粘贴位置

**默认位置**:

- 粘贴到画布中心
- 或粘贴到鼠标位置（如果支持）

**偏移规则**:

- 粘贴多个图形时保持相对位置
- 可选的偏移量（避免完全重叠）

### 11.3.4 粘贴到此处

**快捷键**: `Cmd/Ctrl + Shift + V`

**功能**: 粘贴到鼠标当前位置

**实现**: 使用鼠标位置作为粘贴参考点

## 11.4 跨画布复制粘贴

### 11.4.1 数据格式

**标准格式**: JSON 字符串

**优势**:

- 可跨浏览器标签页
- 可跨应用程序
- 可持久化保存

### 11.4.2 兼容性

**版本检查**:

- 检查应用版本
- 版本不兼容时提示用户
- 支持向后兼容（可选）

### 11.4.3 数据迁移

**迁移规则**:

- 自动处理版本差异
- 转换旧格式数据
- 处理缺失的属性

## 11.5 图片粘贴

### 11.5.1 图片检测

**检测方式**:

- 检查剪贴板中的文件
- 检查文件类型是否为图片
- 支持多种图片格式

### 11.5.2 图片处理

**处理流程**:

1. 读取图片文件
2. 转换为 base64 或 URL
3. 创建图片图形
4. 添加到场景图
5. 选中新创建的图形

### 11.5.3 支持的格式

**图片格式**:

- PNG
- JPEG/JPG
- GIF
- WebP
- SVG（未来支持）

### 11.5.4 图片尺寸

**默认尺寸**: 使用图片原始尺寸

**位置**: 画布中心或鼠标位置

## 11.6 复制为 SVG

### 11.6.1 SVG 导出

**功能**: 将选中图形导出为 SVG 代码

**快捷键**: `Cmd/Ctrl + Shift + C`

**实现位置**: `packages/core/src/to_svg.ts`

### 11.6.2 SVG 格式

**输出格式**: SVG XML 字符串

**包含内容**:

- 图形路径数据
- 填充和描边信息
- 变换信息
- 样式信息

### 11.6.3 SVG 用途

**使用场景**:

- 复制到其他设计工具
- 嵌入到网页
- 导出为文件

## 11.7 剪贴板事件处理

### 11.7.1 事件监听

**监听方式**:

```typescript
window.addEventListener('paste', pasteHandler);
```

**事件处理**:

- 检查事件目标
- 排除文本输入框（特殊情况除外）
- 检查剪贴板数据

### 11.7.2 事件过滤

**过滤条件**:

- 文本编辑器激活时不处理
- 输入框聚焦时不处理（文本编辑器输入框除外）
- 只处理图片文件或文本数据

## 11.8 剪贴板数据序列化

### 11.8.1 序列化流程

1. 获取选中图形列表
2. 遍历图形，收集数据
3. 处理图形关系
4. 转换为 JSON 格式
5. 字符串化

### 11.8.2 数据转换

**ID 处理**:

- 保留原始 ID（用于内部引用）
- 粘贴时生成新 ID

**坐标转换**:

- 世界坐标 → 相对坐标
- 考虑父容器变换

**关系处理**:

- 保留父子关系
- 处理组关系
- 处理嵌套关系

## 11.9 剪贴板数据反序列化

### 11.9.1 反序列化流程

1. 解析 JSON 字符串
2. 验证数据格式
3. 生成新图形 ID
4. 创建图形对象
5. 恢复图形关系
6. 计算粘贴位置

### 11.9.2 新 ID 生成

**生成方式**: UUID

**用途**: 确保图形 ID 唯一性

**实现**: `genUuid()` 函数

### 11.9.3 位置计算

**计算方式**:

- 使用画布中心作为参考点
- 或使用鼠标位置作为参考点
- 保持图形相对位置

## 11.10 剪贴板管理器生命周期

### 11.10.1 初始化

**时机**: 编辑器创建时

**操作**:

- 绑定复制快捷键
- 绑定粘贴事件监听

### 11.10.2 销毁

**时机**: 编辑器销毁时

**操作**:

- 解绑快捷键
- 移除事件监听
