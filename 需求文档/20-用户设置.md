# 20. 用户设置详细需求

## 20.1 设置系统概述

### 20.1.1 设置管理器 (Setting)

**位置**: `packages/core/src/setting.ts`

**核心职责**:

- 管理全局设置
- 提供设置 API
- 处理设置持久化
- 管理设置变化事件

### 20.1.2 设置类型

**设置值类型**:

```typescript
export type SettingValue = Setting['value'];
```

**包含设置**:

- 画布设置
- 工具设置
- 视图设置
- 网格设置
- 标尺设置
- 性能设置

## 20.2 设置分类

### 20.2.1 画布设置

**背景颜色**:

- `canvasBgColor`: 画布背景色
- 默认: `#f4f4f4`

**缩放设置**:

- `zoomMin`: 最小缩放 (0.015625)
- `zoomMax`: 最大缩放 (256)
- `zoomStep`: 缩放步长 (0.2325)
- `invertZoomDirection`: 反转缩放方向

### 20.2.2 工具设置

**工具行为**:

- `keepToolSelectedAfterUse`: 使用工具后保持选中
- `dragBlockStep`: 拖拽阻尼步长

### 20.2.3 视图设置

**标尺**:

- `enableRuler`: 显示标尺
- `rulerWidth`: 标尺宽度
- `rulerBgColor`: 标尺背景色

**网格**:

- `enablePixelGrid`: 显示像素网格
- `snapToGrid`: 网格吸附
- `gridSnapX`: X 轴网格间距
- `gridSnapY`: Y 轴网格间距

### 20.2.4 吸附设置

**对象吸附**:

- `snapToObjects`: 对象吸附开关
- `refLineTolerance`: 参考线容差

### 20.2.5 性能设置

**渲染优化**:

- `showPerfMonitor`: 显示性能监控
- 其他性能相关设置

## 20.3 设置管理

### 20.3.1 设置初始化

**默认值**:

- 预定义的默认设置值
- 支持部分覆盖

**初始化流程**:

1. 创建 Setting 实例
2. 应用默认值
3. 加载用户偏好
4. 合并设置

### 20.3.2 设置更新

**更新方式**:

```typescript
// 更新单个设置
setting.set('enableRuler', true);

// 更新布尔设置（切换）
setting.toggle('enableRuler');
```

**事件通知**:

```typescript
setting.on('update', (value, changedKey) => {
  // 处理设置变化
});
```

## 20.4 设置持久化

### 20.4.1 本地存储

**存储位置**: localStorage

**存储键**: `suika-user-preference`

**存储内容**:

```json
{
  "enablePixelGrid": true,
  "snapToGrid": true,
  "enableRuler": false,
  "keepToolSelectedAfterUse": false,
  "invertZoomDirection": false
  // ... 其他设置
}
```

### 20.4.2 存储策略

**选择性存储**:

- 只存储用户偏好设置
- 排除默认设置
- 减少存储大小

**存储键列表**:

```typescript
const storeKeys = [
  'enablePixelGrid',
  'snapToGrid',
  'enableRuler',
  // ... 其他需要持久化的设置
];
```

### 20.9.2 设置监听

**组件监听**:

```typescript
// 在组件中使用
const setting = useSetting();
const rulerEnabled = setting.get('enableRuler');

// 监听变化
useEffect(() => {
  const handler = () => {
    // 更新组件状态
  };
  setting.on('update', handler);
  return () => setting.off('update', handler);
}, []);
```
