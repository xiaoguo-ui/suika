# 1. 项目概述

## 1.1 项目简介

**Suika Graphics Editor** 是一款开源的基于 Canvas 实现的矢量图形编辑器，功能类似 Figma。该项目采用现代化的前端技术栈，提供了完整的图形编辑能力，支持单用户和多用户协作两种模式。

- **项目名称**: Suika Graphics Editor
- **项目类型**: 开源矢量图形编辑器
- **技术基础**: Canvas 2D API
- **开发语言**: TypeScript
- **UI 框架**: React 18.2.0
- **构建工具**: Vite 5.0.8
- **包管理器**: PNPM (workspace 模式)
- **作者**: xigua
- **许可证**: MIT

## 1.2 项目定位

Suika 旨在提供一个功能完整、性能优秀的 Web 端矢量图形编辑器，主要特点包括：

1. **轻量级**: 基于原生 Canvas，无需依赖重型图形库
2. **功能完整**: 涵盖图形创建、编辑、变换、对齐等核心功能
3. **可扩展**: 采用模块化架构，易于扩展新功能
4. **协作支持**: 支持多人实时协作编辑（需要后端支持）
5. **跨平台**: 基于 Web 技术，支持多平台访问

## 1.4 项目结构

项目采用 Monorepo 架构，使用 PNPM workspace 管理多个包：

```
suika/
├── apps/                          # 应用目录
│   ├── suika/                     # 单用户编辑器应用
│   ├── suika-multiplayer/         # 多人协作编辑器应用
│   └── docs/                      # 文档应用
├── packages/                      # 核心包目录
│   ├── common/                    # 通用工具函数
│   ├── geo/                       # 几何计算库
│   ├── core/                      # 编辑器核心逻辑
│   ├── components/                # UI 组件库
│   └── icons/                     # 图标库
├── scripts/                       # 构建脚本
├── nginx/                         # Nginx 配置
└── Dockerfile                      # Docker 配置
```

## 1.5 技术栈

### 1.5.1 核心依赖

- **React**: ^18.2.0 - UI 框架
- **TypeScript**: ^5.2.2 - 类型系统
- **Vite**: ^5.0.8 - 构建工具
- **Sass**: ^1.57.1 - CSS 预处理器

### 1.5.2 编辑器核心

- **Canvas API**: 图形渲染
- **事件系统**: 鼠标、键盘、触摸事件处理
- **坐标系统**: 场景坐标、视口坐标、屏幕坐标转换
- **变换矩阵**: 图形变换计算

- **yjs**: ^13.6.17 - CRDT 数据结构
- **@hocuspocus/provider**: ^2.13.5 - WebSocket 协作提供者
- **y-websocket**: ^2.0.3 - WebSocket 连接

### 1.5.4 UI 组件

- **react-intl**: ^6.3.2 - 国际化
- **react-color**: ^2.19.3 - 颜色选择器
- **@floating-ui/react**: ^0.22.3 - 浮动 UI 定位
- **classnames**: ^2.3.2 - CSS 类名管理
- **ahooks**: ^3.7.4 - React Hooks 工具库

### 1.5.5 工具库

- **fractional-indexing**: 排序索引生成

## 1.7 开发环境

### 1.7.1 环境依赖

- Node.js (LTS 版本推荐)
- PNPM 包管理器

### 1.7.2 安装步骤

```bash
# 安装 PNPM
npm install -g pnpm

# 安装依赖
pnpm install

# 启动开发服务器（单用户版）
pnpm run dev

# 启动开发服务器（多人协作版）
pnpm run dev-m

# 构建生产版本
pnpm build
```

### 1.7.3 构建产物

- 单用户版构建产物: `apps/suika/build`
- 多人协作版构建产物: `apps/suika-multiplayer/build`
