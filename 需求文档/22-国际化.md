# 22. 国际化详细需求

## 22.1 国际化概述

### 22.1.1 React Intl

**技术栈**: `react-intl`

**位置**: `apps/suika/src/locale/`

**支持语言**:

- 英语 (en)
- 中文 (zh)

### 22.1.2 语言文件

**位置**: `apps/suika/src/locale/`

**文件结构**:

```
locale/
├── index.ts          # 语言配置入口
├── zh.json          # 中文翻译
└── en.json          # 英文翻译
```

### 22.1.3 语言切换

**存储位置**: localStorage

**存储键**: `suika-locale`

**检测逻辑**:

```typescript
const getLocale = (): SupportedLocale => {
  const locale = localStorage.getItem('suika-locale') || navigator.language;
  return locale.startsWith('zh') ? 'zh' : 'en';
};
```

## 22.2 翻译管理

### 22.2.1 翻译键格式

**命名规范**:

```
category.subcategory.keyName
```

**示例**:

```json
{
  "tool.select": "选择",
  "command.undo": "撤销",
  "setting.grid.pixelGrid": "显示像素网格"
}
```

### 22.2.2 翻译键分类

**工具相关**:

- `tool.*`: 工具名称和描述

**命令相关**:

- `command.*`: 命令名称

**设置相关**:

- `setting.*`: 设置项名称

**UI 元素**:

- 按钮、菜单、对话框等

### 22.2.3 翻译内容

**完整性检查**:

- 所有语言文件包含相同键
- 翻译内容准确完整
- 专业术语统一

## 22.3 React Intl 集成

### 22.3.1 应用配置

**IntlProvider 配置**:

```tsx
<IntlProvider locale={locale} messages={messageMap[locale]}>
  <App />
</IntlProvider>
```

### 22.3.2 组件使用

**FormattedMessage**:

```tsx
<FormattedMessage id="tool.select" />
```

**useIntl Hook**:

```tsx
const intl = useIntl();
const text = intl.formatMessage({ id: 'tool.select' });
```

### 22.3.3 动态内容

**变量插值**:

```tsx
<FormattedMessage
  id="selectedItems"
  values={{ count: selectedCount }}
/>
```

**复数形式**:

```tsx
<FormattedMessage
  id="itemsCount"
  values={{ count }}
/>
```

## 22.4 语言切换

### 22.4.1 切换机制

**全局事件**:

```typescript
// 触发语言切换
appEventEmitter.emit('localeChange', newLocale);

// 监听语言切换
appEventEmitter.on('localeChange', (locale) => {
  // 更新应用语言
});
```

### 22.4.2 持久化

**存储策略**:

- 切换时保存到 localStorage
- 应用启动时恢复语言设置

### 22.4.3 实时切换

**组件更新**:

- 语言切换时重新渲染
- 保持应用状态
- 无需刷新页面
